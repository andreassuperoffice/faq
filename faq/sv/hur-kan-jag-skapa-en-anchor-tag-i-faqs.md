# Hur kan jag skapa en anchor tag i FAQs?

Uppdaterad på 3. dec. 2021

Ibland kan dina FAQ's bli långa och dedikerade till mer än en användargrupp, eller beskriva mer än en situation. Hur tillåter man användare att hoppa igenom texten för att nå den relevanta delen lättare?

Med SuperOffice kan du enkelt skapa en anchor tag som gör att användarna kan hoppa igenom texten för att nå den relevanta delen lättare.

HTML-taggarna för ett anchor är:

<a href="#anchor"> Länktext </a> - för texten

<a name="anchor"> </a> - för platsen i texten där den ska ta fram.

Låt oss ta ett exempel där du vill förklara två sätt att återställa lösenordet. För att lära dig hur man gör det, följ stegen nedan:

1. Öppna en FAQ där du vill använda en anchor tag.
2. Klicka på knappen Källa. Då öppnas din FAQ i HTML format.

   ![](https://cs.superoffice.com/scripts/customer.fcgi/getAttachment/2782172-jb4pOTsMekR9aMJ72g5oLJwMJOfugu2iLu4gGWWPl62OnTT9ceSS7EOO3I6lcgLk-0/2016-10-27_11-53-05.png)
3. I koden, hitta den text som du vill använda för att kunna klicka på och skapa ett ankare.

   ![](https://cs.superoffice.com/scripts/customer.fcgi/getAttachment/2782189-LHCXRPnDP0M8Ajt0DZ6M6FWgZ7cbApdwU8hOTD8pmQ3oYgOYRsQdg8Tz5IjcA0e1-0/2016-10-27_12-04-00.png)
4. I koden hitta den plats dit du vill omdirigera din läsare och gör den andra delen av din anchor tag.

   ![](https://cs.superoffice.com/scripts/customer.fcgi/getAttachment/2782253-LodW8ybQjSjBM4QlCxpbLFHow67AhXuItKYDHgLNmGrLbQs0wo6nLP7AumWlQoPe-0/2016-10-27_12-09-53.png)
5. Gå tillbaka till redigeringsläge genom att klicka på Source-knappen igen och spara din FAQ. Om du vill se hur det ser ut i praktiken klickar du på länken i exemplet nedan.
