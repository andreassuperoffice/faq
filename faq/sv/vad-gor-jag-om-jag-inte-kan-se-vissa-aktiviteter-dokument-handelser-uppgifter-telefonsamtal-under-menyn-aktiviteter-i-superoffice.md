# Vad gör jag om jag inte kan se vissa aktiviteter (dokument, händelser, uppgifter, telefonsamtal) under menyn Aktiviteter i SuperOffice?

Uppdaterad på 8. jan. 2026

I aktivitetsfliken under företagskortet kan jag inte hitta vissa av de aktiviteter vi har gjort med kunden. Min kollega kan se dem. Varför händer det och hur kan jag åtgärda det?

Det finns fyra kända orsaker till varför du inte kan se vissa av aktiviteterna. Vänligen se dem beskrivna nedan:

1. [Filterinställningar för datum eller grupper för medarbetare.](https://community.superoffice.com/sv/support-faqs/faq/vad-gor-jag-om-jag-inte-kan-se-vissa-aktiviteter-dokument-handelser-uppgifter-telefonsamtal-under-menyn-aktiviteter-i-superoffice/#1)
2. [Filterinställningar i verktygsfältet i botten för fliken aktiviteter.](https://community.superoffice.com/sv/support-faqs/faq/vad-gor-jag-om-jag-inte-kan-se-vissa-aktiviteter-dokument-handelser-uppgifter-telefonsamtal-under-menyn-aktiviteter-i-superoffice/#2)
3. [Privata aktiviteter, alterantivt dubletter som per standard är satta att ej visas.](https://community.superoffice.com/sv/support-faqs/faq/vad-gor-jag-om-jag-inte-kan-se-vissa-aktiviteter-dokument-handelser-uppgifter-telefonsamtal-under-menyn-aktiviteter-i-superoffice/#3)
4. [Inställning för "Visa dagar i förväg".](https://community.superoffice.com/sv/support-faqs/faq/vad-gor-jag-om-jag-inte-kan-se-vissa-aktiviteter-dokument-handelser-uppgifter-telefonsamtal-under-menyn-aktiviteter-i-superoffice/#4)

**1. Filterinställningar för datum eller grupper för medarbetare**

För att säkerställa att en filterinställning inte orsakar att vissa aktiviteter inte syns behöver du:

1. Tryck på Filter knappen under aktivitets fliken.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6389099-sjWUNyUDWg8yTooJCjxMCJZLOnBhdLs0CnSbKAWi6eoy14ETiQ1I0i6h02thZzfm-0/image-20251104131349-1.png)
2. I filterdialogrutan kan du justera två kriterier: tidsramen när aktiviteten skapades och användaren som skapade den. I fälten Datum (1) kan du ändra tidsramen och förlänga den om du tror att aktiviteten kan ha skapats tidigare. I kolumnerna Grupper (2) och Medarbetare (3) kan du välja vems aktiviteter som ska visas i listan. Du kan använda genvägen Alla (4) om du vill se aktiviteter skapade av alla. Klicka på OK för att spara inställningarna.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6389114-bS8I4bBfQIsuFUBaXpx22u6zDWMM6RAIg0mB71RtlS1YdBm2iNQLZ1tMKu1UHa9W-0/image-20251104131640-3.png)

**2. Filterinställningar i verktygsfältet i fliken för aktiviteter.**

De aktiviteter som visas beror på vilka av följande kryssrutor du har valt längst ner i tabben:

- Uppföljningar (möten, uppgifter och telefonsamtal)
- Dokument (e-post, brev och andra dokument)
- Utskick (dokument, e-post eller SMS)
- Övrigt (chatt-sessioner, formulärinlämningar)

**3. Privata aktiviteter samt dubletter av aktiviteter är per standard valda att inte visas.**

Det betyder att om din kollega har skapat ett möte som endast är synligt för henne, så kommer det inte att vara synligt för dig. Vänligen kolla [denna FAQ](https://community.superoffice.com/en/support-faqs/faq/how-do-i-make-some-of-my-activities-invisible-from-other-superoffice-users-private/) för mer information.

Duplicerade möten som skapats av flera kontakter som bjudits in till mötet är som standard dolda för alla utom den kontakt som gör inbjudan. Detta kan ändras, följ stegen nedan för att göra det:

1. Tryck på ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6270401-wpWGW5dZr9KPXloqJbGxyj0DhJ8ji3kxUKJqyoxYUHxQBYBjR3msFmYgLeyfKHyS-0/image.png) och sedan Inställningar:

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6389118-L5EpoUxArAJsgaSra3mrxsahAj2IzKNfJaA7fftw6X8FYbJA5lIdfp26gHJEd8JG-0/image-20251104131942-7.png)
2. Klicka på **Funktioner** (1) och bredvid **Filterade accepterade förfrågningar** (2) välj **Nej**. Klicka på **Spara** (3) när du är klar.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6389129-tBcjJJnII0zjn2EynflKUJ0AZo4WYPNXEOp155jzwanbrxXCHKc44jWm0fIefi3T-0/image-20251104132444-8.png)

**4. Inställning för "Visa dagar i förväg"**

Vissa händelser (av typ uppgift eller telefonsamtal) kan vissa gånger inte vara synliga under aktiviteter eftersom att dem är bokade för dagar längre fram i tiden än vad SuperOffice visar. För detta fall kan du ändra hur många dagar framåt i tiden som aktiviteter skall vara synliga. För att göra detta:

1. Tryck på ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6270401-wpWGW5dZr9KPXloqJbGxyj0DhJ8ji3kxUKJqyoxYUHxQBYBjR3msFmYgLeyfKHyS-0/image.png) och sedan Inställningar:

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6389118-L5EpoUxArAJsgaSra3mrxsahAj2IzKNfJaA7fftw6X8FYbJA5lIdfp26gHJEd8JG-0/image-20251104131942-7.png)
2. Klicka på **Funktioner**och hitta fältet **Visa dagar framåt,**i detta fält skriv in antalet dagar framåt i tiden som du önskar att se aktiviteterna.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6389131-awILQ7S129olY9YFgtA1m6kLpRGwHsO8R2Gb5bKuqCqgfy5uZPPqc05RjO0bIwC8-0/image-20251104132601-9.png)
