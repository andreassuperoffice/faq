# Hur kan jag uppdatera vårt SuperOffice CRM?

Uppdaterad på 27. mars 2026

Hur kan vi uppgradera vårt SuperOffice CRM?

Observera att SuperOffice Online automatiskt uppgraderas till den senaste versionen för alla kunder. Om du använder SuperOffice Onsite finns det två sätt att uppgradera din SuperOffice CRM-lösning:

1. Våra certifierade partners och konsulter kan utföra uppgraderingen åt dig. Vänligen kontakta din kundansvarig för att ordna uppgraderingen.
2. Du kan uppgradera ditt SuperOffice på egen hand. SuperOffice-programvara kan laddas ner från SuperOffice Community [Product Release](https://community.superoffice.com/sv/product-releases/) när du har ett programunderhållsavtal med SuperOffice.

   **Notera!**

1. För att kunna ladda ner programvaran måste du vara registrerad och inloggad på [SuperOffice Community](https://community.superoffice.com/sv/).
2. Du måste informera din kundansvarig i SuperOffice när du planerar att uppgradera, eftersom detta kan innebära ändringar i licensstrukturen för SuperOffice CRM och vissa åtgärder måste utföras i våra backendsystem.
