# Hur kan jag skicka utskick till företagens mejladress?

Uppdaterad på 2. dec. 2021

Jag vill skicka ett utskick till våra kunder och jag vill använda e-postadresserna som är sparad i fältet E-post på företagskortet. Hur gör jag det?

![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4560934-fyKwjnY6YZc0H92jczfSf0Mm9dMEstX3ZnFpHz7zwIAXb6L845pgNKanu4AtNhOz-0/image.png)

Vanligtvis skickas utskick till personer (kontakt - e -postfält). Det är dock möjligt att skicka ett utskick till en e-postadress som lagras på ett företagskort. För att göra det, följ stegen nedan:

1. Skapa ett urval av företag som ska få utskick. Kontrollera den här [artikeln](https://community.superoffice.com/en/customer/learn/standard/selections/create-search-save-as-selection/) för att ta reda på hur du gör.
2. Skapa sedan ett utskick som ska skickas. Kontrollera den här [artikeln](https://community.superoffice.com/en/customer/learn/marketing/mailings/) för att se hur du gör det.
3. När du når steget **Mottagare** (1) väljer du **Urval** (2) och hittar det urval du har skapat. Klicka på **plusknappen** (3) för att lägga till listan över mottagare. Välj sedan **Inkludera företag** (4) och **Föredrar företag** (5). Klicka på **Nästa** (6) för att fortsätta konfigurera utskick.

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4560935-4CNqEqm7rwTiInkH5GuYrIgSqOZBjduiQyiZS0kn2ypc4kdZ7q7UsZBAi6i0whEP-0/image.png)

   **Notera!** Om du bara väljer alternativet Inkludera företag kommer SuperOffice att inkludera företagets e-postmeddelanden bara om huvudkontaktfältet på företagskortet är tomt. Annars kommer den att använda e-postadressen för kontakten som anges i fältet Huvudkontakt. När du också väljer Föredrar företags-alternativet kommer SuperOffice fortfarande att använda e-postadressen som sparas i fältet E-post på företagskortet även om ett företag har huvudkontaktfältet fyllt.
