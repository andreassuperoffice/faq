# Hur får jag och börjar använda SuperOffice för Outlook-tillägg?

Uppdaterad på 31. okt. 2025

Hur får jag och börjar använda SuperOffice för Outlook-tillägg?

SuperOffice for Outlook är ett Outlook-tillägg som gör det möjligt att arkivera e-postmeddelanden och utföra ytterligare åtgärder mot din SuperOffice CRM. Det här tillägget fungerar på alla enheter där du har Outlook installerat,  det är Outlook för Windows, för Mac, för Android eller iOS. För att få tillägget SuperOffice for Outlook behöver du helt enkelt lägga till det i Outlook där ditt Office 365-e-postkonto är installerat och det kommer automatiskt att finnas tillgängligt på alla andra enheter var du använder Outlook-applikationen med samma konto. Följ stegen nedan för att lära dig hur du får detta

- Om du vill aktivera SuperOffice för Outlook i Outlook för Windows, följ  [detta avsnitt.](https://community.superoffice.com/sv/support-faqs/faq/hur-far-jag-och-borjar-anvanda-superoffice-for-outlook-tillagg/#1)
- Om du vill aktivera SuperOffice för Outlook i Outlook-webbläsarapplikation, följ  [detta avsnitt.](https://community.superoffice.com/sv/support-faqs/faq/hur-far-jag-och-borjar-anvanda-superoffice-for-outlook-tillagg/#2)

**Lägg till SuperOffice for Outlook i Windows Outlook-applikationen**

1. Öppna din Outlook och klicka på fliken som heter **File**:

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6145065-565dWgQmPbf85Kp70kb5FytTFGLYXrDsKMJSUQHoTST0lx8bUHtTkliNRxOQD1Eg-0/image-20250325163417-1.png)
2. Sedan klicka på **Manage Add-ins** knappen:

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6145068-8RUUyTHgIIEN2dpqdEnEASnRlsLZiNDdE79QxCHH62LMiWFuDPgmZKszAogU8yFH-0/image-20250325163443-2.png)
3. Skriv in SuperOffice i det högra hörnet och klicka på tillägget **SuperOffice for Outlook.**

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6145071-Btj7zg2iKAiK0SiHPtdf7R2waTNYobsQBaX9yiBOPjFAkJQfKTlBzwO1Dxp8e8fO-0/image-20250325163603-3.png)
4. Klicka på knappen **Add** och SuperOffice för Outlook läggs till i din Outlook.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6145075-cLT0FN6aZXUUYBzU7ZhfiiFq3ERDe6Crb97yA28yqRBQqIoOWz8fP9rzS75aB29t-0/image-20250325163816-4.png)
5. Den nya knappen **SuperOffice for Outlook** (1) visas i Outlook-ribbon, klicka på den. Första gången blir du ombedd att ansluta till din SuperOffice, vänligen klicka på **We run SuperOffice Online (2)** eller **We run SuperOffice Onsite (3)** beroende på vilken installation du använder.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6145079-RqrrHkQ32naMJQBiRbwSi4Wcgc3a04IohiZqKD62aA2LlJ7NogY4iMc8SiIeYWOw-0/image-20250325164005-5.png)
6. Om du använder SuperOffice Online kommer du se Inloggninssida. Ange gärna ditt användarnamn så kommer du fram till din identitetsleverantör.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6145094-5qzEkbMlWcUgjBKz604x2XiDTccl7qoTsZyont75E6edje1JEzeXqQcZcfIQSX7t-0/image-20250325164505-6.png)
7. Du blir ombedd att skriva in din Server URL, användarnamn och lösenord om du använder SuperOffice Onsite.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6145279-GQWNMISlziYSaNHOrbpsOCEx9Ex26XEBanqaerFNxk0p3U99BRZP3jXOjEA7LbDD-0/image-20250325172129-20.png)

   När SuperOffice för Outlook har anslutit till din SuperOffice CRM-installationen kan du börja använda den.

**Lägg till SuperOffice för Outlook i Outlook-applikationen i webbläsaren**

1. Klicka på App ikonen i din web Outlook och sedan Add apps.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6145226-yfY1K3lIA3wN5ANYpGOM49JLgxKQJi4pkH9bci3Fb9Ns49wUP4U0GXIjsPuIse6w-0/image-20250325170625-8.png)
2. Microsoft App Store ska öppnas, skriv SuperOffice for Outlook i sökrutan och klicka på appen som dyker upp.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6145227-lRjDJitxGbHH5hXOPbo3iS7nyqp6InHq6yhmJKkzEKf08DyfGWhfUtAOnHp19q8O-0/image-20250325170816-9.png)
3. Sedan klicka på **Add.**

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6145236-py3rNRxTnt01yCWlIgp07K4SEIme8gdJB3oufrRhFloPgYGjGEOn0St4fydo9atk-0/image-20250325171119-10.png)
4. Gå sedan till din Outlook Inbox och tryck på **SuperOffice** knappen på mejlet. Första gången du gör det blir du ombedd att logga in.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6145245-Hola35oyXTKhPty2OxlmdpEdWM6JFIIZjJXFI8Xd8xIklqghNXoN2WKy634JtTJ0-0/image-20250325171450-11.png)
5. Vänligen välj **We run SuperOffice Online (2)** eller **We run SuperOffice Onsite (3)** beroende på vilken installation du använder.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6145247-AMdf76IzJj3rqxyongIecURuqrg71Tjc9ltQJsKPXrhgilxWg2XY9DU2eFTXe8yl-0/image-20250325171730-12.png)
6. Om du använder SuperOffice Online kommer du se Inloggninssida. Ange gärna ditt användarnamn så kommer du fram till din identitetsleverantör.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6145094-5qzEkbMlWcUgjBKz604x2XiDTccl7qoTsZyont75E6edje1JEzeXqQcZcfIQSX7t-0/image-20250325164505-6.png)
7. Du blir ombedd att skriva in din Server URL, användarnamn och lösenord om du använder SuperOffice Onsite.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6145279-GQWNMISlziYSaNHOrbpsOCEx9Ex26XEBanqaerFNxk0p3U99BRZP3jXOjEA7LbDD-0/image-20250325172129-20.png)

   När SuperOffice för Outlook har anslutit sig framgångsrikt till din SuperOffice CRM-installation kan du börja använda den.
