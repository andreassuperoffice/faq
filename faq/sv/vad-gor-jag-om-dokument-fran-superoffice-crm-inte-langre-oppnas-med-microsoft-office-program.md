# Vad gör jag om dokument från SuperOffice CRM inte längre öppnas med Microsoft Office program?

Uppdaterad på 22. juni 2026

Jag brukade kunna öppna, redigera och spara dokument från SuperOffice CRM med Microsoft Office-program. Nu laddas dokument från SuperOffice CRM ner och öppnas lokalt, och ändringar som görs i befintliga dokument sparas inte tillbaka till SuperOffice CRM.

Varför händer detta och hur löser jag det?

De beskrivna situationerna kan uppstå när SuperOffice WebTools inte är installerat eller inte är anslutet till din dator. Följ stegen nedan för att lösa problemet:

[Steg 1. Se till att SuperOffice WebTools är installerat](https://community.superoffice.com/sv/support-faqs/faq/vad-gor-jag-om-dokument-fran-superoffice-crm-inte-langre-oppnas-med-microsoft-office-program/#1)

[Steg 2. Se till att SuperOffice WebTools är anslutet till SuperOffice CRM](https://community.superoffice.com/sv/support-faqs/faq/vad-gor-jag-om-dokument-fran-superoffice-crm-inte-langre-oppnas-med-microsoft-office-program/#2)

[Steg 3. Konfigurera SuperOffice WebTools med ditt SuperOffice CRM konto](https://community.superoffice.com/sv/support-faqs/faq/vad-gor-jag-om-dokument-fran-superoffice-crm-inte-langre-oppnas-med-microsoft-office-program/#3)

​

**Steg 1. Se till att den senaste versionen av SuperOffice WebTools är installerad**

1. Öppna program och funktioner på din dator.
2. Kontrollera att SuperOffice Web Extensions finns i programlistan. Tryck [här](https://community.superoffice.com/sv/product-releases/release-notes/) för att hitta versionen av den senaste releasen.

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6746493-EpTpfPYlX1oxNo5quD8kycJHwXhimIRGDntgHro0BhItdQnCFtubYMRuzbXx69hw-0/image-20260621203609-1.png)
3. Om du inte hittar Web Extensions behöver du installera och konfigurera det. Läs [denna FAQ](http://community.superoffice.com/en/support-faqs/faq/how-do-i-download-and-install-webtools-for-superoffice-crm/) för mer information om hur du gör det.

​

**Steg 2. Se till att SuperOffice WebTools är anslutet till SuperOffice CRM**

1. Högerklicka på WebTools-ikonen i det högra hörnet på din dator och välj Preferences. Om du inte ser ikonen betyder det att WebTools inte kan startas. Kontakta din IT-administratör för att se till att SuperOffice.TrayApp.Client.Exe alltid är aktivt.

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6746499-uOQYYsyw8kKf2PtpJA233sBtWnKnN8o5gXAMwuJHQEF090CNtXLTaiKMeikBdH3E-0/image-20260621205854-7.png)
2. Under WebTools **preferences**, kontrollera om du ser ditt Företagsnamn:

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6136881-fjrSeJWTwphrYqfUtUr8KPoJl8RQwZ2AqjcLK3L36bUWs8iy1s5O7DdGLx59AZpn-0/image-20250320080412-3.png)

   Om det är tomt där betyder det att WebTools inte är korrekt konfigurerade. Vänligen gå till sista steget (steg 3) i denna FAQ.
3. Om du ser ditt företagsnamn, stäng Preferences-fönstret. Högerklicka på SuperOffice WebTools-ikonen igen och välj Login.

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6746500-qpgA2K0CIc9UboOEMJunDse5MjaOLwyascz4GkSAaZlCKAx9NIEZ3U2lKa2n5YAn-0/image-20260621210133-8.png)

   I den nya tabben som öppnas, testa att öppna något separat dokument. Om det fortfarande inte öppnas i Office-applikationen, fortsätt med steg 3.

**Steg 3. Konfigurera SuperOffice WebTools med ditt SuperOffice CRM konto**

Detta steg behövs bara om steg 2 visade att dina WebTools inte är korrekt konfigurerade. Lita alltid på steg 2 först.

1. Tryck på personliga inställningar i det högra hörnet och välj **Ladda ned - SuperOffice WebTools:**

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6748498-pydxCG4GE0AW5GWBu63qZXPeIt6ZHIJKWC8z3aq06M2DWa654agJHHmd2G8Dr1Rw-0/image-20260622161244-1.png)
2. Ett av två olika fönster för att ladda ned SuperOffice WebTools öppnas.

   **- Om du ser fönstret Arbeta snabbare med dokument**, klicka på Klicka här för att ansluta.

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6748550-yKde4Rt0tDHhYbPOh8OS9pueAiAX5ZiJBAkTdnfK0PmIDgEIWj8aSKzSZB8sWAjc-0/image-20260622162614-3.png)

   **- Om du ser fönstret Personal computer Home/Office**, välj Personal computer Home/Office, välj den e-postklient du använder och gå vidare till nästa skärm. Klicka sedan på Klicka här för att koppla WebTools till den här SuperOffice-installationen.

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6748504-MQHztw9OMELrh5H2D0en5gYH6IKf72Ad5ocEEfhCdo8QShSnmamQ0yI2JX2RkWyJ-0/image-20260622161445-2.png)
3. När filen har laddats ner, tryck på den för att öppna filen:

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6746497-eUeHLRgEI6jq5FSl4G5lafQiYSLq44RDZFR1E3Ntd68rxaEiyGDnGXtEhpwalZte-0/image-20260621205357-5.png)
4. Du kommer att se dialogen i hörnet på din skärm som säger att SuperOffice behöver autentisera dig mot din SuperOffice-installation. Tryck på OK, då kommer processen startas i webbläsaren och när det har skett kommer du se ett Success meddelande:

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/5375273-ldhZOkZc0oMWHk04PcjJco1atgRuXiryowZBd5fnrcsl4xi0d3lkTYUXYtXfjrKr-0/image-20230501112308-5.png)

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/5375272-PmPp9tuP544hSFsyAu3sAdPGtqao4H8dGyz9JCUecc7SdKIf9J0j8d2K9jqRouwM-0/image-20230501112259-4.png)

   **Notera**! Om du använder en autentiseringsleverantör (Microsoft 365 eller Google), kan du bli omdirigerad till deras webbsida för att autentisera dig igen (ange ditt användarnamn och lösenord) för att slutföra anslutningen till din SuperOffice.

   Tryck då OK och ladda om din webbläsare.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6136889-hTUHoxQ8sImqaIYl3SfAXY0GwhOBL5P9yBHwA5W4xjeb9AbB8gA0gGFzF7xqYI4t-0/image-20250320080905-1.png)

**Obs!** Denna FAQ förklarar hur du felsöker SuperOffice Web Extensions, som används för att öppna och spara dokument från SuperOffice CRM. Om e-postmeddelanden inte längre öppnas i Outlook och du fortfarande använder MailLink, kontrollera att MailLink är installerat och konfigurerat. MailLink installeras separat från Web Extensions. Du hittar mer information [här](https://community.superoffice.com/en/support-faqs/faq/why-is-maillink-not-installed-when-i-download-webtools/).
