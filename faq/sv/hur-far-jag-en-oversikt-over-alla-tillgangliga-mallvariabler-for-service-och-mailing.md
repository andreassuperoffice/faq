# Hur får jag en översikt över alla tillgängliga mallvariabler för Service och Mailing?

Uppdaterad på 3. dec. 2021

Hur får jag en översikt över alla tillgängliga mallvariabler som jag kan använda för Service och Mailing?

Du kan använda mallvariabler för att infoga information från ditt SuperOffice CRM i kommunikationsmeddelanden med kunder. Klicka på en av länkarna nedan för att få en översikt över alla tillgängliga mallvariabler i postmodul eller tjänst.

- [Om du vill få variabler i Service.](https://community.superoffice.com/sv/support-faqs/faq/hur-far-jag-en-oversikt-over-alla-tillgangliga-mallvariabler-for-service-och-mailing/#anchor1)
- [Om du vill få variabler i Marknadsföring.](https://community.superoffice.com/sv/support-faqs/faq/hur-far-jag-en-oversikt-over-alla-tillgangliga-mallvariabler-for-service-och-mailing/#anchor2)

**Skaffa en lista över alla tillgängliga mallvariabler du kan använda i svarsmallar i SuperOffice Service**

1. Klicka på **Kunskapsbas**(1) och **Svarsmallar** (2).

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4395432-LL9Z3gNL7drAqHz69pFTjXI8KNhnJAREtnIZy0HNTuaqPjXkTkNF67h8QBo0XIKx-0/image.png)
2. Klicka på knappen **Ny svarsmall**i de högra hörnet för att skapa en ny svarsmall. Kontrollera den här [artikeln](https://community.superoffice.com/Documentation/Help/se/CRM/8.5/UserHelp/index.htm#t=Service%2Ftopics%2Fdocument.replyTemplates.html&rhsearch=reply%20templates&rhhlterm=reply%20templates&rhsyns=%20) om du vill veta mer om hur du skapar svarsmallar.

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4395433-2qRcY7MwKnbAPgpP2OwY847hdS0gM7UoaDIznRFnodx77PnrUjBWlcGMjd8eqhax-0/image.png)
3. För att få en lista över alla mallvariabler kan du antingen skriva **"**%PARSER\_TREE%" (2) i fliken **HTML-tex**t (1) eller klicka på **Mallvariabler** (3) och välja ett objekt i **Lista med tillgängliga mallvariabler** (4) och spara en mall genom att klicka på **OK** (5).

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4395434-3OSZ2N8GkehdihT8rZgbOaY6uO9YuFf7w5l1dZWJbqEy6y7AkXbqobabgce8ZfY9-0/image.png)

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4395435-xJckUucocc6MMU51xbcN8juU2HzJUOcfLT5ODcfeWoyr1juexGZG4TmXK7xFM3rm-0/2020-07-20_13-53-36.jpg)
4. När du sedan använder den här svarsmallen på begäran kommer den att ta med alla tillgängliga mallvariabler, som kan användas och värden, som skulle ha fyllts i mallen som använder mallvariabeln.

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4395437-ZPFO5uMuyxKtqhdknYexsSZ5SNN7PMkyH50pREURZdqEWS2HYXF4g3kIMrt6TOBR-0/image.png)

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4395439-4ArfyM70M9NiQfa6QJrO1CB8CnDPrJPJc1hB0nt89OgdazPyuAkYy7EkZk2zFp4s-0/image.png)
5. För att använda mallvariabler skriver du bara dem inom parentes i svarsmallen och nästa gång du använder den här mallen för svar, kommer informationen i mallvariabel att fyllas i med informationen från SuperOffice CRM.

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4395440-jPYAsog6o6OAuwoyjJoSloEmC3fazNGhaq2xANQe4kB5h9O1F1fdPyRqdaGFEoFa-0/image.png)

**Skaffa en lista över alla tillgängliga mallvariabler du kan använda i meddelandet i SuperOffice Marknadsföring**

1. Öppna ett e-postmeddelande som du kan använda för att testa och klicka på knappen **Redigera stycke** (1).

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4395441-f1QhLWMROnxUD1oSgBYa6qOKYDOYzmqIMM3WaBk5guDI80m6wYOhbf3esMrIIaeX-0/image.png)
2. Klicka på fliken **Brödtext** (1) sedan på **Mallvariabler** (2) och välj ett objekt i **Lista över tillgängliga mallvariabler** och spara stycket genom att klicka på **OK** (3).

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4395442-nre5XF9onY6rKR3TcQQtZN6yfdbFXBtU12XetB3KIJ3Yo1DROmdDBWKmZUEWTxq5-0/image.png)
3. Klicka på **Skicka test** (1) -knappen i det nedre hörnet för att skicka testmeddelandet till dig själv (2). Klicka på **OK** (3) för att göra det.

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4395443-ExbthMpptHO5ltQXCXepp1xP03DQCqDxrCu5t64MosHwcLcbSejpppgsz7a9uOC3-0/image.png)
4. Kolla din e-post, du hittar ett meddelande som visar alla möjliga mallvariabler som du kan använda i Marknadsföring.

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4391379-0Sg4ty9ews3gu85Zo3gRbEQ4O3m9uZmrRlOzM0NPiyCW6oHU9XMALcf5UY8AQTCG-0/image.png)
5. Nästa gång du skapar ett e-postmeddelande, skriv det helt enkelt inom parentes i textstycket och när du skickar e-post kommer informationen i mallvariabel att fyllas i med informationen från SuperOffice CRM automatiskt.

**Notera!** Du kan också använda en mallvariabel, som skulle ta med dagens datum i meddelandet. Variabel formas på följande sätt: % FORMAT\_DATE: system (dateTime), "YY4 MM2 DD2"% Du kan också ändra datumutmatningen genom att ändra det variabla formatet. Nedan finns alternativ som du kan använda.

YY4 = år, fyra siffror
YY2 = år, 2 siffror
MM2 = månad, 2 siffror
MM1 = månad, 1 eller 2 siffror
DD2 = dag i månaden, 2 siffror
DD1 = dag i månaden, 1 eller 2 siffror
MONTH = månadens namn. Matris med namn måste skickas som tredje argument.
WDAY = Veckodagens namn. Uppsättning av namn, börjar med söndag, som fjärde argument.

HH24: Tid på dygnet, 2 siffror, 24 timmars format
H24: Tid på dygnet, 1 eller 2 siffror, 24-timmars format.
HH12: Tid på dygnet, 2 siffror, 12 timmars format.
H12: Tid på dygnet, 1 eller 2 siffror, 12 timmars format
MI2: Minuter. 2 siffror.
SS2: Sekunder. 2 siffror.
AMPM: FM / EM-indikator, "am" eller "pm"
