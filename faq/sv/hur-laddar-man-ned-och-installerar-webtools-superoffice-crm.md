# Hur laddar man ned och installerar WebTools SuperOffice CRM?

Uppdaterad på 31. juli 2026

Hur laddar man ned och installerar WebTools SuperOffice CRM?

När du loggar in i SuperOffice CRM för första gången kan du bli ombedd att uppgradera eller installera SuperOffice WebTools. Om installationsguiden inte visas, eller om du behöver ladda ner SuperOffice WebTools igen, följer du stegen nedan:

Logga in på SuperOffice CRM och i menyn högst upp klicka på knappen ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6525912-m0tgj5bQCWjz900bREW4b5Pb3XuUEhHOYtK4tJFqxjD68uoGa452yFWGuh4o3fEQ-0/image-20260209103324-1.png), sedan klicka på **Ladda ned** och välj **SuperOffice WebTools**.

![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6800095-d6xwHCtgjs4JBrBs0ffEwS4sYhUtpdFMCbNbFDb66ObOHOMNRac5wQgU9dQ7qlZO-0/image-20260731160423-1.png)

Nästa fönster kan se olika ut beroende på ditt operativsystem och din SuperOffice-installation. Följ avsnittet som motsvarar det du ser:

- [Klicka här om du använder Windows och ser fönstret Arbeta snabbare med dokument.](https://community.superoffice.com/sv/support-faqs/faq/hur-laddar-man-ned-och-installerar-webtools-superoffice-crm/#t1)
- [Klicka här om du använder Windows och ser fönstret Personlig dator Hem/Kontor.](https://community.superoffice.com/sv/support-faqs/faq/hur-laddar-man-ned-och-installerar-webtools-superoffice-crm/#t2)
- [Klicka här om du använder SuperOffice WebTools på Mac-operativsystemet.](https://community.superoffice.com/sv/support-faqs/faq/hur-laddar-man-ned-och-installerar-webtools-superoffice-crm/#mac)

**Windows: Fönstret Arbeta snabbare med dokument**

1. Klicka på Ladda ner för att börja ladda ner WebTools.

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6800096-jUdDC34W8toWCRE1p9T04Wmufs38lQlEtwZcYORlzcgpM4nPjAd4wjyJaDwuAuJM-0/image-20260731160727-2.png)
2. Installationsfilen för SuperOffice WebTools laddas ner till mappen Hämtade filer på din dator. Dubbelklicka på filen för att starta installationsguiden.

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6793469-2xMxXheo1jeNEiePSPh3qbzkry3eFJejTFhELKC8uYtLPBou9cbIGo3OtzLS2Ckq-0/image-20260724112327-18.png)
3. Klicka sedan på Install för att starta installationen.

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6793429-09HQA9TLxMnxrWHHzh74EN6kE18sQxLmKu5y3gMh9bGa8HtyaxKgpuhZ0BaDUMnN-0/image-20260724105631-6.png)
4. Du kommer att se ett meddelande om att WebTools är anslutet till din SuperOffice CRM-installation. Klicka på OK för att stänga meddelandet.

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6793476-DRdf1ef1E9ZA39e0RfuWj3sTxBj4NrIY7R2gE1EDGf8UTeYKR9eHi8q42lylPEbi-0/image-20260724112833-20.png)
5. Klicka på Close för att stänga installationsguiden.

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6793438-LDa4qPWjPcqrmy0knjaUe08SE0XCfl1R1tT0z373fYq2geg9YNuclseifJH10ocM-0/image-20260724111201-12.png)
6. Klicka sedan på Close för att avsluta installationsguiden för WebTools.

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6800104-81WQsoMPxzQZhMt6tYhP7cwLoHMi8Sp0sI1sdl1QRZCrAbaEhzuN2r7SpliMdwuW-0/image-20260731160900-3.png)

**Windows: Personlig dator Hem/Kontor**

1. Välj **Privat dator Hem/kontor** och fortsätta med **Nästa**.

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6800105-dzd47ntCoPMEDzBIPul6YUKsd7tpLzn2EalkJJxjr44p4urSMAm21ajwd4EX4sCm-0/image-20260731161204-4.png)
2. Välj den e-posttjänst som du vill koppla med ditt SuperOffice CRM.

- ​Om du använder Outlook e-postklient, klicka bara på **Outlook**-ikonen och på **Nästa**.
- Om du använder Gmail, klicka på den andra ikonen och **Nästa.** [Denna FAQ](https://community.superoffice.com/sv/support-faqs/faq/how-do-i-setup-gmail-link-and-connect-my-gmail-account-with-superoffice-crm/) förklarar hur man kan konfigurera gmail konto med SuperOffice CRM.
- Om du föredrar att använda SuperOffice e-postklient, klicka på den tredje knappen och Nästa. [Denna FAQ](https://community.superoffice.com/sv/support-faqs/faq/how-do-i-start-using-the-superoffice-inbox/) förklarar hur konfigurera den.

![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6800106-IfgRUDeSBTG53d66eKRmeaaDAntz5LJ1QckDw7LZhDDKp46hTkxSSFCHFPzBrs7L-0/image-20260731161239-5.png)

3. Klicka på **Ladda ned SuperOffice WebTools.**

![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6800107-4bt0u4Bap8YMgqQebW54G4121nAJXSrpUe0XwWXOszYMEtguSpcaoDOP8bohuInf-0/image-20260731161255-6.png)

4. SuperOffice WebTools-installern ska laddas ner till dina hämtade filer.

![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6793469-2xMxXheo1jeNEiePSPh3qbzkry3eFJejTFhELKC8uYtLPBou9cbIGo3OtzLS2Ckq-0/image-20260724112327-18.png)

5. Klicka sedan på **Installera.**

![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6793429-09HQA9TLxMnxrWHHzh74EN6kE18sQxLmKu5y3gMh9bGa8HtyaxKgpuhZ0BaDUMnN-0/image-20260724105631-6.png)

6. Under installationen kommer WebTools att ansluta till ditt SuperOffice CRM. Du bör få ett meddelande, klicka på **OK** för att färdigställa.

![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6793432-IhlhQmbP3NuCMMZxOUrjNebmJfLpNDfRkpZ3gTJaxerlSXEsgAqp5PJYfG9sn50g-0/image-20260724110350-7.png)

7. Autentiseringen fortsätter i din webbläsare. När du ser bekräftelsemeddelandet stänger du webbläsarfliken.

![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6793467-mGi9yYnorjzt9brxM54PZF6UAaWXtiuOLquoH2MwNb3ab6EQ7FFGpDNEdhOAfx6Y-0/image-20260724111622-16.png)

8. Du kommer också att se ett meddelande om att WebTools är anslutet till din SuperOffice CRM-installation. Klicka på OK för att stänga meddelandet.

![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6793477-G8FNiG2chSCjS0rODwJEnYsPUgDM4WIgo2NFbb8KdyO5sOKfBLbsr64OwUZ6HjxW-0/image-20260724112929-21.png)

9. Klicka på **Close** för att stänga installern.

![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6793438-LDa4qPWjPcqrmy0knjaUe08SE0XCfl1R1tT0z373fYq2geg9YNuclseifJH10ocM-0/image-20260724111201-12.png)

10. Sedan klicka på knappen **Stäng**för att avsluta WebTools installationen.

![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6800108-Hi52YiyXiiXEGfSjsaKw5pfbnTxf8FJEUH7YIdAGQ2cKFGw7NJnZ8nf0KbZAH5ht-0/image-20260731161645-7.png)

**Obs!**

Med den nya e-postanslutningen ingår MailLink inte längre i installationsprogrammet för WebTools. Om du behöver MailLink måste det laddas ner och installeras separat från [SuperOffice Download Service](https://downloadservice.superoffice.com/).

Läs mer i FAQ:n: [Why is MailLink not installed when I download WebTools?](https://community.superoffice.com/en/support-faqs/faq/why-is-maillink-not-installed-when-i-download-webtools/)

**Installera SuperOffice webbverktyg på Mac-operativsystem**

1. Tryck på Ladda ned WebTools:

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6800109-Nkj16ZNCUN3sUf6DpMefPm6XtxQQoDQTrakn3iMCwW81LppIEE721ABAGnOTa2ut-0/image-20260731162224-8.png)
2. Tillåt nedladdningar på online.superoffice.com

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6793465-A7Tx7nKK67FgIih4EHKzJSuoW5DFRt3gMOMD80wTABLQyXIKHlq03Waz6stLXJRJ-0/image-20260724111408-14.png)
3. SuperOffice WebTools fil kommer att laddas ner på din dators Downloads flik. Öppna filen i **DiskImage**och dra den till applikationsflik i din Mac:

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6147973-4B7RKxF6XTwRwySJMFTtSpLhasXQLmiWXwM1HRkaOdm6JiqEW5QbW7UiDzCm1H3y-0/image-20250327105735-16.png)
4. SuperOffice kommer att behöva autentisera dig, tryck på OK:

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6793466-0R3Luwnk2Usc8lXyZz9OrCttqekRDeqzwRxmE7HepKCPe8oNpfa6aQHoCjD0cc8n-0/image-20260724111501-15.png)
5. Du ska komma fram till detta fönster och kan stänga ner det:

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6793467-mGi9yYnorjzt9brxM54PZF6UAaWXtiuOLquoH2MwNb3ab6EQ7FFGpDNEdhOAfx6Y-0/image-20260724111622-16.png)
6. Tryck på Stäng för att slutföra installationen.

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6800108-Hi52YiyXiiXEGfSjsaKw5pfbnTxf8FJEUH7YIdAGQ2cKFGw7NJnZ8nf0KbZAH5ht-0/image-20260731161645-7.png)
