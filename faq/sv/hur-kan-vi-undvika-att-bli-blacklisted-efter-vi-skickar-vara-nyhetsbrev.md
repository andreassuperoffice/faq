# Hur kan vi undvika att bli blacklisted efter vi skickar våra nyhetsbrev?

Uppdaterad på 8. jan. 2026

Jag använder SuperOffice Mailings för att skicka kommunikation till kunderna. Många av utskicken hamnar på svarta listor och rapporteras som skräppost. Vad kan jag göra åt det?

Det finns många möjliga anledningar till varför ni blir svartlistade. Några av dem kan vara:

1. Mottagarlistan som du använder har dålig kvalitet. Vi rekommenderar att du använder [prenumerationshantering](https://docs.superoffice.com/sv/marketing/recipients/learn/manage-email-subscriptions.html) för att säkerställa att dina skickade meddelanden är relevanta för dina mottagare.

2. Om du använder SuperOffice CRM Online, vänligen läs [denna FAQ](https://community.superoffice.com/sv/support-faqs/faq/what-to-do-when-my-sent-mailings-bounce-in-superoffice-online-or-i-get-many-bounce-messages-in-superoffice-service/) som förklarar hur du kan undvika att bli markerad som skräppost.

3. Om du använder SuperOffice Onsite kan det hända att länkar som skapats i nyhetsbreven har formatet som hänvisar till customer.exe. .exe-hänvisningen ses som ett hot av skräppostfilter. För att undvika detta, försök att använda en URL-omskrivning eller en länkförkortare för att dölja 'customer.exe' i länkarna. Om detta inte hjälper, vänligen [registrera en supportförfrågan](http://cs.superoffice.com).

4. Det kan hända att du hade några tillfälliga problem, men efter att du löst dem har din domän eller IP-adress redan förlorat ett gott rykte. För att kontrollera om din domän är svartlistad kan du använda en gratis webbtjänst som [MXToolbox](https://mxtoolbox.com/blacklists.aspx).
