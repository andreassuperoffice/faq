# Hur ändrar jag mitt lösenord i SuperOffice CRM Onsite?

Uppdaterad på 31. jan. 2022

Hur ändrar jag mitt lösenord i SuperOffice CRM Onsite?

Det finns tre sätt att ändra ditt lösenord när SuperOffice CRM är installerad på er egen server:

- [Byt själv ditt lösenord](https://community.superoffice.com/sv/support-faqs/faq/hur-andrar-jag-mitt-losenord-i-superoffice-crm-onsite/#1).
- [SuperOffice CRM administratör kan byta lösenord åt dig.](https://community.superoffice.com/sv/support-faqs/faq/hur-andrar-jag-mitt-losenord-i-superoffice-crm-onsite/#2)
- [En SuperOffice system användare kan byta åt er.](https://community.superoffice.com/sv/support-faqs/faq/hur-andrar-jag-mitt-losenord-i-superoffice-crm-onsite/#3)

**Byt själv ditt lösenord.**

Om du använder samma lösenord (och användarnamn) för att logga in på din datorn och i andra program och enheter (Active Directory-autentisering) kan du ändra lösenordet i systemet där eran autentiseringen hanteras.

Kunder använder ofta Microsoft för att hantera användarnamn och lösenord för SuperOffice CRM. Om du behöver hjälp med att förstå var ditt lösenord är lagrat, kontakta din SuperOffice CRM-administratör.

**SuperOffice CRM administratör kan byta lösenord åt dig.**

Om du använder ett unikt lösenord för SuperOffice CRM så kan du be din SuperOffice-administratör att återställa ditt lösenordet. Administratören bör följa dessa steg:

1. Logga in på [Inställningar och Underhåll](https://online2.superoffice.com/Cust1990/CS/scripts/customer.exe?_sf=0&custSessionKey=&customerLang=no&noCookies=true&action=viewKbEntry&id=10106).
2. Gå till **Användare (1)**i navigatorn på vänster sidan och välj fliken **Medarbetare (2).** Välj sedan den användaren som ni söker (3) i listan. I fältet **lösenord(4)** skriver ni in ett nytt temporärt lösenord. tryck sen på Go to the **Users (1)**section and then, in the **Associates (2)**tab find the user and select it (3) from the list. In the **Password** (4) field type a temporary password for one time login and **Save** (5)the user. **Spara (5).**  Informera sedan användaren det nya temporära lösenordet.

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4742010-kNQEBsIXYEXGbM1S9iGPTbEIK7gK7mcb9wFcltEi2H0DbkiE6DOR56ckOCBsMzBg-0/image.png)
3. När du får information om att lösenordet har ändrats loggar du in i SuperOffice CRM med det tillfälliga lösenordet. Klickan på din användarikon och väljer Ä**ndra lösenord.**

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4742011-ruU1jwWfIJkfWAMC6qbrOGooi5p2Cuw1xmbgwIGJS7n10inFOFmm7Qd3UM0fL0xQ-0/image.png)
4. Skriv in ditt temporära lösenord och skapa ett nytt [Säkert](https://passwordsgenerator.net/) lösenord.

**En SuperOffice system användare kan byta åt er.**

Om du är den enda användaren av SuperOffice CRM med administratörsbehörighet och du har glömt ditt lösenord kan du logga in till på [Inställningar och underhåll](http://online2.superoffice.com/Cust1990/CS/scripts/customer.exe?_sf=0&custSessionKey=&customerLang=no&noCookies=true&action=viewKbEntry&id=10106) med en system användare och återställa ditt lösenord.

Inlogg för er system användare finns i den tekniska installations dokumentationen. SuperOffice lagrar inte denna information och kan därför inte tillhandahålla denna typ information.
