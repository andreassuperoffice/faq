# Hur ändrar jag ett glömt lösenord i SuperOffice CRM Online?

Uppdaterad på 11. maj 2026

Hur ändrar jag ett glömt lösenord i SuperOffice CRM Online?

Instruktionerna för hur du ändrar ett glömt lösenord beror på identitetsleverantören (ID) som stry lösenordet:

- Om du använder SuperOffice som tjänst för autentisering, klicka [här.](https://community.superoffice.com/sv/support-faqs/faq/hur-andrar-jag-ett-glomt-losenord-i-superoffice-crm-online/#1)
- Om du använder Microsoft som tjänst för autentisering, klicka [här.](https://community.superoffice.com/sv/support-faqs/faq/hur-andrar-jag-ett-glomt-losenord-i-superoffice-crm-online/#2)
- Om du använder Google som tjänst för autentisering, klicka [här.](https://community.superoffice.com/sv/support-faqs/faq/hur-andrar-jag-ett-glomt-losenord-i-superoffice-crm-online/#3)

**Notera!** Om du inte vet vilken tjänst för autentisering ni använder, kontakta din IT-ansvarige.

​

**SuperOffice som tjänst för autentisering.**

När SuperOffice ansvarar för lösenord finns det två sätt att ändra det på:

- Ändra lösenordet själv:

  1. Klicka på **Glömt lösenordet?** som visas efter att du har angett din e-postadress.

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6274434-40gXLhhKdukk9KXosuEBgyZZ9sQZQfK5MDAEnZhQLOdzXc39w5eD7Rd6M5teeF6R-0/image-20250723093208-1.png)

  2. Du kommer att omdirigeras till <https://id.superoffice.com/forgot-password>där du behöver fylla i din e-postadress och klicka på **Skicka e-post-knappen** för att få ett e-post för återställning av lösenord. Följ instruktionerna i e-postmeddelandet för att återställa ditt lösenord.

  ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6676969-olzAGEFPf2Ha7bH69CzfWYJTt0xsCuTPRIozokoFttaOLQ0e01QZ64HpJtO4g1El-0/image-20260511163624-1.png)
- Be din SuperOffice systemadministratör att ändra lösenordet för dig i SuperOffice **[Inställningar och underhåll](https://community.superoffice.com/sv/support-faqs/faq/hur-far-jag-tillgang-till-att-administrera-installningar-och-underhall-superoffice-crm/)**

  1. Administratören ska välja användare i Navigator-menyn till vänster och hitta ditt användarkonto på fliken **Medarbetare**.

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6527960-ZZXXjFLWQo8GJumN6fp06QZLJGps3O9s5gwHnNYkZk9d0KKRRH8xXzFWH5QUzRXw-0/image-20260210084548-1.png)

  2. Välj ditt användarkonto och klicka på knappen **Uppgift** längst ner på skärmen och välj sedan alternativet Skicka återställ lösenord via e-post. Följ instruktionerna i e-postmeddelandet för att återställa ditt lösenord.

  ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6677059-FTQOAuhCxaCW9zobFC0XXj2P6LgYuQpceGrytaWkd6BFU7Ox2CJqyKMKr0NfII1Q-0/image-20260511172039-2.png)

​

**Microsoft som tjänst för autentisering**

När Microsoft ansvarar för ditt lösenord måste det återställas via Microsofts återställningstjänst. Den här **[artikeln](https://docs.microsoft.com/en-us/microsoft-365/admin/add-users/reset-passwords?view=o365-worldwide#reset-my-office-365-tenant-admin-password)** förklarar hur du återställer lösenordet i MS Office 365.

​

**Google som tjänst för autentisering**

När Google ansvarar för ditt lösenord måste det återställas via Googles återställningstjänst. Den här **[artikeln](https://support.google.com/a/answer/33319?hl=en)** förklarar hur du återställer ditt lösenord i G Suite.
