# Vad gör jag när jag inte får skicka dokument som epost i SuperOffice?

Uppdaterad på 2. dec. 2021

Jag vill skicka ett dokument som epost. När jag högerklickar på dokumentet är jag ej tillåten att välja "Skicka som epost" - knappen är gråmarkerad. Varför händer detta, och vad kan jag göra?

![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4773429-Uf2ytfe5pwa1WY6nC1OYhICJtRrhdI4n609iWrsI1rM9Xqot2SmSA2FgJFM1gEB6-0/image.png)

Den här situationen kan uppstå när dina e-postklientinställningar i SuperOffice CRM är inställda på att använda SuperOffice CRM-inkorgen som en huvudsaklig e-postklient och du inte har inkorgen konfigurerad. Följ stegen nedan för att felsöka det:

1. Klicka på ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4358008-zFJEGWYire2BYert5MUKYGX0NT5cbaSg0EW1tzdqBIp8Er5GxgcRL58zRIuMEnwR-0/image.png) knappen och sedan på **Lokala inställningar**.

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4773435-pk7ohOhpbNX5mupZAPHjTLiDxDN9kZlziDlNpHQzx71ZErx1bLHW3h1JRNAD0Nm6-0/image.png)
2. Välj sedan alternativet **SuperOffice CRM** under **E-postklient** om du vill använda den integrerade inkorgen för att skicka och ta emot e-post. Om du väljer **Microsoft Outlook** kommer detta program att användas för e-posthantering.

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4773437-MAnDdpTXka5Biuaz2F3lSkTsyFkGQdGnOBkbetTRyOQsJUjSpgTgPQAWD5zI358G-0/image.png)
3. Konfigurera e-postklienten med dina e-postdetaljer:

- Om du väljer att använda SuperOffice CRM, följ stegen i [denna FAQ](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi?_sf=0&custSessionKey=&customerLang=en&noCookies=true&action=viewKbEntry&id=113760)**.**
- Om du väljer att använda Microsoft Outlook, se till att [SuperOffice Web Tools](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi?_sf=0&custSessionKey=&customerLang=en&noCookies=true&action=viewKbEntry&id=113786) är installerade på din dator.
