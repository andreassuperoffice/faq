# Hur ställer jag in aviseringar för uppföljningar i SuperOffice CRM?

Uppdaterad på 21. mars 2022

Jag vill bli påmind om uppföljningarna som jag har skapat i min SuperOffice-dagbok. Hur ställer jag in aviseringarna?

För att kunna påminnas (få aviseringar) eller uppföljningsaktiviteter i ditt SuperOffice CRM, se till att SuperOffice Web Tools är installerade och konfigurerade. Denna [FAQ](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi?_sf=0&custSessionKey=&customerLang=en&noCookies=true&action=viewKbEntry&id=113786) förklarar hur man gör det.

Följ stegen nedan för att ställa in dina uppföljningar för att visa aviseringar i förväg:

1. Börja med att skapa en uppföljning. Du kan antingen klicka på **+ Nytt** och sedan på **Möte (1)** eller **Telefonsamtal (2**) eller **+ Lägg till (3) i** fliken Aktiviteter.

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4647771-Et0eo6zJUJsNgOamHoR2uShp84hKIZ0frfAgiGIbFhUWBHrH2MEJnpRZtjCfZw8m-0/image.png)

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4647779-kurS3yzBkJaC5r4B7bf6lxLJXlpzuICeEll5eAksrHCgpgi9X4kUPF6ihS8iTrPP-0/image.png)
2. Klicka sedan på **Detaljer (1)** och lägg till en bock bredvid **Alarm (2)**. Ange antalet minuter för hur lång tid innan påminnelsen om händelselarm ska dyka upp. Klicka på **Spara (3)** för att avsluta.

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4647793-mdKdUIktNMb4Y4XRFLoFGmpgAWrQe2sMa2L9LtW2169CuCFq4glJuSYHpDez1aiw-0/image.png)

**Notera!**

1. Du kan använda olika tidsformat: dagar, timmar och minuter - för att ange hur mycket tid innan händelsen en avisering ska dyka upp. Om du vill konfigurera att ett meddelande dyker upp några dagar före händelsen, ange tiden i följande format, till exempel 1d 2h 35m.
2. Det tidigaste meddelandet i SuperOffice Online och Web som kan anges så att det visas är 22 d. 18h. och 07 min; medan i SuperOffice Windows kan det tidigaste meddelandet planeras till 45 d
   .
3. När aviseringstiden kommer, Öppnas Larmdialogrutan med information om företaget, datum, tid, typ, prioritet och plats som uppföljningen är kopplad till. Denna dialogruta innehåller följande alternativ:

- Klicka på **OK (1)** för att bekräfta att du har sett informationen.
- Klicka på **Visa (2)** för att öppna uppföljningsdialogen och visa mer information.
- Markera för att **påminn mig om 5 minuter (3)** och klicka på **OK** för att upprepa larmet.

  ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4395327-FsLQlI79FmB7y7tJTAG6kLfZMYXyudTuKoP7i3OQhGCjEqnCtW8OZHMLANmh6EuI-0/image.png)

**Notera!**

1. För att larm (aviseringar) ska fungera i en annan tidszon än din standardtid måste [tidszonsinställningen vara aktiverad](https://help.superoffice.com/Documentation/Help/SE/CRM/10.0/WebHelpAdmin/index.htm#t=chap06%2FActivating_time_zones_web.htm&rhsearch=time%20zone&rhhlterm=time%20zone&rhsyns=%20).
2. Du kan ställa in SuperOffice CRM-inställningar, som gör det möjligt att automatiskt få aviseringar till alla dina uppföljningar. Detta kan göras antingen i personliga inställningar i avsnittet **Kalender (1)**, bredvid **Alarmstart för uppföljning (2)** genom att fylla i antalet minuter när påminnelser ska dyka upp före uppföljning. Eller i dialogrutan Inställningar för Web Tools genom att lägga till en bock bredvid **Visa larm för alla möten ... minuter innan** och infoga antalet minuter i det tomma fältet.

   Du kan konfigurera när larmet ska stoppas genom att ange tiden bredvid alternativet **Tyst efter (3)**.
