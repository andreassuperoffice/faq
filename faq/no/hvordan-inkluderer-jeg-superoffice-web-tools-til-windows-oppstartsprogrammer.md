# Hvordan inkluderer jeg SuperOffice Web Tools til Windows Oppstartsprogrammer?

Oppdatert på 8. des. 2021

Etter at jeg har startet på datamaskinen min, må jeg koble opp SuperOffice Web Tools på nytt. Hvordan sørger jeg for at SuperOffice Web Tools kobles automatisk til etter at datamaskinen har startet om igjen?

For å inkludere SuperOffice WebTools til Windows Startup-applikasjoner, følg trinnene nedenfor:

1. Åpne Windows Task Manager (Oppgavebehandling)

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/3010236-LzIal0t288bshYNS6nsQ4amubNZJBlHirNcSrSDYLdhiyS9hDfXnBKhMS7CIrsqg-0/image.png)
2. Åpne **Startup**-fane og høyreklikk på **SuperOffice Web Tools**

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/3010238-OGoRgjBH6ojPRcrLEEk7k5EIbeqtUQmWrL49Ts0joGQybreESDZhNWBOOKHdqyW8-0/image.png)
3. Velg **Aktiver** (enable) i menyen

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/3010243-P9Nhm6hoygaPfP6QQY4mD0WQIPInXEjSOJ7op2qDlztMbSL0PEq2mzniJiuzkdnK-0/image.png)
4. Nå blir SuperOffice Web Tools koblet opp automatisk hver gang datamaskinen blir slått på.

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/3010244-P0nrK0Xw8eBerMw5m5iKp6xBoP6bbeZnFhchjkDeEeYanD4bNbEFCEgB2AGhqboW-0/image.png)
