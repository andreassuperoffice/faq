# Hvordan kan jeg administrere SuperOffice CRM?

Oppdatert på 28. apr. 2026

Hvordan får jeg tilgang til SuperOffice CRM's Administratormodul?

For å få tilgang til Innstillinger og vedlikehold må din SuperOffice-bruker tilhøre [en brukergruppe](https://docs.superoffice.com/no/admin/user-management/role/index.html) som har administrative [rettigheter](https://community.superoffice.com/no/support-faqs/faq/hvilke-funksjonelle-rettigheter-er-tilgjengelige-i-superoffice-og-hva-betyr-hver-av-dem/). Vennligst se [denne FAQ-en](https://community.superoffice.com/no/support-faqs/faq/hvordan-konfigureretilgangsrettigheter-som-brukere-i-superoffice-crm-har/) for å lære mer om hvordan du konfigurerer tilgangsrettigheter i din SuperOffice.

Når brukeren din har nødvendige rettigheter, kan du få tilgang til SuperOffice-administratormodulen ved å trykke på knappen ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6652493-pXBUTKa7qLY9MNW4Y8mqoo5e4xawaUfm7LicJ52a4n0Dq9IHTLP6ZSLXdmNJ0YFX-0/image-20260428121144-1.png) og deretter **Innstillinger og vedlikehold.**

![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6652604-CKt6HrP4H9iXugfrXYgLb1rtxzDT9tuIUq3kqBr9p8taJkMWIgfSOJDUZbHOTsqH-0/image-20260428122135-3.png)

**Merk!**

1. Fra SuperOffice 8 er Administratormodulen nettbasert (kun tilgjengelig via nettleseren).
2. For å lære hvordan du bruker Administratormodulen i SuperOffice CRM, kan du se [disse artiklene](https://docs.superoffice.com/en/admin/index.html).
3. URL-eksemplene for å få tilgang til Administratormodulen er:

             - For Onsite: [Your installation URL]admin/default.aspx?

             - For Online: https://online.superoffice.com/[YourCustID]/admin/default.aspx?

          Hvis du ikke kjenner URLen til SuperOffice Web-installasjon, ta kontakt med deres IT-ansvarlige.
