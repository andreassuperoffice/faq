# Hvordan kan jeg se alle våre saker i alle kategorier i SuperOffice Service?

Oppdatert på 28. apr. 2026

Hvordan kan jeg se alle saker som er registrert i alle [kategorier](https://docs.superoffice.com/no/request/admin/category/index.html) i SuperOffice Service?

For å kunne se alle saker i alle kategorier må en SuperOffice-bruker ha følgende oppsett i SuperOffice [Innstillinger og vedlikehold](https://community.superoffice.com/no/support-faqs/faq/hvordan-kan-jeg-administrere-superoffice-crm/):

1. SalesPremiumServicePremiumMarketingPremium eller Service Brukerplan. Dette kan konfigureres på brukerkortet i SuperOffice.

![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6509912-LD8b55hGxORbgz6Co5s0K7y9q1GR1zjFK7bN5QpnmAqxBhkPZ5UHEebXg9wEgUKE-0/image-20260130102357-1.png)

2. Brukeren må ha en rolle som har følgende **funksjonelle rettigheter**: *List all requests, Read all requests, Edit all requests.*For å tildele disse funksjonelle rettighetene, følg trinnene nedenfor:

1. Noter hvilken **rolle** brukeren har.

![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6466565-eejRuf8FchLneUyjhG36uXUNyyIdcNSG402zIkL1zagSmMdJFtU25X87StQKloi6-0/image-20251230110358-3.png)

2. Klikk på **Roller (1)**, velg rollen (2) som brukeren har, åpne fanen **Funksjonelle rettigheter (3)**, og flytt *List all requests, Read all requests og Edit all requests (4)* til kolonnen **Denne rollen kan:**

![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6509980-SmQeZulxr9kdiiedY6PePlh7KWNogY9L9qdxOXpYo8FiE8f5AO5nXwScd0aSidUm-0/image-20260130103502-2.png)

**Merk!** Det er viktig at rollen **kun** har de tre ovennevnte understrekte funksjonelle rettighetene knyttet til saksbehandling i kolonnen «Denne rollen kan». Hvis kolonnen «Denne rollen kan» inneholder både: *List request in own categories, Read request in own categories, Edit request in own categories* **og samtidig** *List all requests, Read all requests, Edit all requests* vil de førstnevnte rettighetene overstyre de sistnevnte. I dette tilfellet vil du kun se saker i kategorier du er medlem av og ikke alle saker.

![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6509981-hz8DaGNO4TmNSMo7116Edksa8exjhhaWIBSPkoC40wW0uhmfkyWuWTY4lAXaroyp-0/image-20260130103637-3.png)
