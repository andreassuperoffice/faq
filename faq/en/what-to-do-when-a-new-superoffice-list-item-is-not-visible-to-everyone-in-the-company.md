# What to do when a new SuperOffice list item is not visible to everyone in the company?

Updated on 28 Dec 2025

I have created a new list item, but it is not visible to my colleagues. Why does it happen, and how do I fix it?

There are some reasons why new list items are not visible.  This depends on the type of list item that has been created. Please find explanations of what can be done below:

- [The sales stage or project status is not visible](https://community.superoffice.com/en/support-faqs/faq/what-to-do-when-a-new-superoffice-list-item-is-not-visible-to-everyone-in-the-company/#1)
- [Any other (company - category, appointment - type, etc.) list item is not visible](https://community.superoffice.com/en/support-faqs/faq/what-to-do-when-a-new-superoffice-list-item-is-not-visible-to-everyone-in-the-company/#2)

​

**The sale stage or project status is not visible**

Please check the FAQs below to learn the solution:

- [What to do when newly created "Project Status" is not visible in SuperOffice CRM?](https://community.superoffice.com/en/support-faqs/faq/what-to-do-when-newly-created-project-status-is-not-visible-in-superoffice-crm/)
- [What to do when newly created "Sale Stage" is not visible in SuperOffice CRM?](https://community.superoffice.com/en/support-faqs/faq/what-to-do-when-newly-created-sale-stage-is-not-visible-in-superoffice-crm/)

​

**Any other (company - category, follow-up - type, etc.) list item is not visible**

If you cannot see some other list item, make sure that the user group to which your SuperOffice user is assigned has access to the list item that cannot be seen. To illustrate it, let's imagine that your user cannot see the Follow-up type. Please follow the steps of the example below to troubleshoot it:

1. In the [Settings & Maintenance](https://community.superoffice.com/en/support-faqs/faq/how-do-i-access-administration-part-settings--maintenance-in-superoffice-crm/), click on **Lists (1)**, choose **Follow-up - Type (2)** from the drop-down list.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465356-GNtBMwRPuCw06EDRFX0dmaNUYMfPAG418LKWkSqgLyx2egQDQJMhY6cSTOJCTdGp-0/image-20251228122107-1.png)
2. User grouping and filtering have to be enabled (1). Make sure that the list item, which you cannot see (2), has a tick box next to your user group (3) in the box on the right side of the screen.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465357-c4qbkaip4Nf5dFTIPrRtER6CdZWqB8ic9IdlSwKBmzMhsONKjWHcnxjFjA0JY4g0-0/image-20251228122229-2.png)

   **Note!** If you cannot see the list item in the list above, make sure that it has not been deleted. To see all deleted items, add a tick next to the option **Show deleted items and headings**.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465358-MQ5f1bu2nqPrfd3ikLHL4Tb00uxwSb38j8QR2SYS6ika3u7tnxkcRhCN1BU8ED6O-0/image-20251228122407-3.png)
