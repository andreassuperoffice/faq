# What to do when I get an error "Unfortunately, we were unable to log you in to {{applicationIdentifier}}. The error message was Failed validating identity token" when trying to connect SuperOffice Web Tools?

Updated on 28 Dec 2025

I'm trying to connect Web Tools to my SuperOffice, but I get an error in browser:

*Unfortunately, we were unable to log you in to {{applicationIdentifier}}. The error message was Failed validating identity token.*

Why does it happen and how do I fix it?

![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4361285-bxybysIw4ECyjtGxqWs5zH8zzpULo8U8nrLSuK54WUbl2JM6u3dUhSJxUFTU1DxF-0/image.png)

This error comes up when a computer, where SuperOffice Web Tools are being configured, has a different time than the actual time in the original time zone. To solve the problem please follow the steps below:

1. Right-click on the time in Toolbar and click **Adjust date/time.**

![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4361296-9MjfIsacrPc54jazuP7DoEaWe7NXIeE9Dg0Pyti3aSUTOzEGl3iCeCfwxxADeBmD-0/image.png)

2. Click on **Change date and time (1)** to change the time manually or click on **Internet Time (2)** tab.

![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4361293-MRGNXzfsKSCJp8P5kehjZXweLZcsF8lANLnF6dfo6iZaAuo2TfkBsfy0ggrXuMrf-0/image.png)

3. Click on **Change settings.**

![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4361303-ij8AAeyn4rt8iTnw8u4rs3RRcNruz4P1LQynPjWYL8G9XSGdfEFkynYsT7MoxSIX-0/image.png)

4. Add a tick next to **Synchronize with an Internet (1)** time server and click **OK (2).**

![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4361304-mkwwQrnunfJZ8QAdJP6GBkZ1cKM01D9U8t7eY0rYfSYL2yLwXd6ySEqalKDh7ZjM-0/2020-06-15_17-08-43.png)

5. Try to authenticate Web Tools again, [this FAQ](https://community.superoffice.com/en/support-faqs/faq/what-to-do-when-e-mails-and-documents-from-superoffice-crm-stopped-opening-with-microsoft-office-programs/) explains how to do it.

If this did not help to solve the issue, please [register a Support request](https://community.superoffice.com/en/support-faqs/).
