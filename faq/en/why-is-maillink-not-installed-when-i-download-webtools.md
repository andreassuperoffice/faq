# Why is MailLink not installed when I download WebTools?

Updated on 22 Jun 2026

When downloading WebTools on a new computer, only SuperOffice Web Extensions are installed, and MailLink is not included.

![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6604444-HgE33Mr6MZcEWwwl8HPGWoIKFpI8OaKrB1rqiWIeMlu6YXTjtGT5lrezX1DX37ZZ-0/image-20260325155039-1.png)

Why does this happen, and how can I install MailLink?

More and more users are using the new Outlook, which no longer supports COM add-ins.

Because of this, the installation files for **WebTools** have been separated. **From WebTools version 13.2.3**, used together with **SuperOffice version 11.11** **or newer**, only Web Extensions are included by default, and MailLink is no longer installed automatically.

If you are using the classic version of Outlook and still need MailLink, you must download and install it separately:

- You can download MailLink from the SuperOffice Download Service: <https://downloadservice.superoffice.com/>

  ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6724066-UbgO8rMqlPUE4HKx8epSgN33stRIqcjETZrudS2Jn6FTnpWMdArALl33iw1hTutd-0/image-20260608144815-1.png)

  To configure MailLink to work with classic Outlook, follow the steps below:

  1. Close Outlook.

  2. Run the MailLink setup wizard.

  3. Open Outlook again.

  You may be prompted to accept the installation. If this happens, click Install.

  ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6748817-mpbljkiag9zbtOBJrSBd8zqJuLZbz5Fs2pqLUmIHCOoOMfnrUJT9yRpArL99Hslb-0/image-20260622234735-1.png)

  If MailLink was previously installed on your computer, it may appear in Outlook immediately after you run the MailLink setup wizard.
- As an alternative, you can use SuperOffice for Outlook, which provides an integration with Outlook regardless of version or device.

**Note!**We recommend using SuperOffice for Outlook when working with the new Outlook, as MailLink is not supported here.
