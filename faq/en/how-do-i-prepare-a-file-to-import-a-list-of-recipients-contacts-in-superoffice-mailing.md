# How do I prepare a file to import a list of recipients (contacts) in SuperOffice Mailing?

Updated on 7 Jan 2026

What do I need to know to prepare a correct import file which could be used to import a list of recipients in SuperOffice Mailing?

When you want to send out a mailing to a list of contacts, you can easily import this list of contacts from a file.

- If your contact list is in Excel format, [click here](https://community.superoffice.com/en/support-faqs/faq/how-do-i-prepare-a-file-to-import-a-list-of-recipients-contacts-in-superoffice-mailing/#1)
- If your contact list is in the .txt format, [click here](https://community.superoffice.com/en/support-faqs/faq/how-do-i-prepare-a-file-to-import-a-list-of-recipients-contacts-in-superoffice-mailing/#2)

​

**If your contact list is in Excel format**

1. If your contact list contains only e-mails, please organize them in one column.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6153320-BPe8TdsSOXw8RUoZTxrOfN5ily8jmxRrgxsacWliNrzw6iSMPm1YWwtPd8nLRJWJ-0/image-20250331141514-2.png)
2. If your contact list contains names, surnames, and e-mails, please make sure that names and surnames appear in one column and e-mail addresses in another.

   **Note!**The import file for Mailing cannot contain any other details about a contact, just name, surname, and e-mail address.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6153313-6PwdPCq4sK0sH9nOkpMcOmX1uwPUx6AxmdMrHHwqPbinPq56c0WxR8pnD2Wi4o1i-0/image-20250331141258-1.png)

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6153643-YmAHBfORIHrJ1hqRJFxaaamMJWM3MzRybbSR6DYDpHKkCZU21T91uk6eELH1enc1-0/image-20250331150050-5.png)
3. Please make sure there are no empty rows between contacts.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6153346-H0Whe5Skr1hCqtAERT9wByN8lMrBQJnWzDm3Qe9AmAF57YjLtoFKIOPfldkkIueg-0/image-20250331141835-3.png)
4. Please make sure that the contacts do not include any signs you don’t want to see in contact’s name or e-mail.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6153569-dWTYRpyykhMdcxFu2QbimwfSERHhGOChZ4DED9dM6eUAq2ARqzpYoMAH09tqlRKM-0/image-20250331144825-4.png)
5. Please make sure that the contact list in the Excel file is saved in the **CSV (Comma-delimited)** format before importing it to SuperOffice Mailing.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6153676-Hx4tPWe4bFA15HybFq0fNExiOLcF10qkDQBadZpMUtF8zBszjzlRSBhCLzLNgyUt-0/image-20250331150455-6.png)

​

**If your contact list is in the .txt format**

1. Please make sure that names (and surnames) are separated by a comma from the e-mails.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6153689-wEqaG0zDZKy4iKMMFbwpE7kLaoxaAezdGQiyRnDXK0lDu3LQh8LlRcYYlyXSrP1f-0/image-20250331150707-7.png)
2. Please make sure there are no empty rows between contacts.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6153690-KF74x8F5MtSNm4Y5cQrWnAbEbyipmEoM5qLmf2Sd8iS8jeEG46enwM6FtJaMTIg9-0/image-20250331150800-8.png)
3. Please make sure there are no additional symbols in your contact list.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6153714-gh1MenTFpA6e11g5drsLIrkZJjZn01aPzjk5jYU11aRkH9ASmfqKHXsqpB5EWl5B-0/image-20250331151305-10.png)

**Note!**

1. Due to the GDPR legislation, only the contacts that have expressed consent to be legally saved in the SuperOffice CRM database and receive information can be added as recipients. When you import a list of names and email addresses, SuperOffice Marketing will try to locate the imported recipients in the SuperOffice database. If matches are found, the recipients' companies are listed in the **Company** column in the **Recipients** list. Any names or email addresses that are **not** found in SuperOffice are filtered out and not included in the mailing. This is due to GDPR regulations.
