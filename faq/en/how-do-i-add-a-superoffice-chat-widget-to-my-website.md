# How do I add a SuperOffice Chat widget to my website?

Updated on 8 Oct 2025

How do I add a SuperOffice Chat widget to my website?

To get the SuperOffice Chat widget active on your website, you must do two actions. Please follow the steps below to do it:

[Step 1. Configure SuperOffice Chat channel](https://community.superoffice.com/en/support-faqs/faq/how-do-i-add-a-superoffice-chat-widget-to-my-website/#1)

[Step 2.  Add the JavaScript to your website's Content Management system](https://community.superoffice.com/en/support-faqs/faq/how-do-i-add-a-superoffice-chat-widget-to-my-website/#2)

**Step 1. Configure SuperOffice Chat channel**

1. Log in to **[Settings & Maintenance](https://community.superoffice.com/en/support-faqs/faq/how-do-i-access-administration-part-settings--maintenance-in-superoffice-crm/).**
2. Select **Chat** **(1)** on the left side of the menu, then [create a chat](https://docs.superoffice.com/en/chat/admin/channel-create.html)[channel](https://docs.superoffice.com/en/chat/admin/channel-create.html)or select one that has been created before (2), and click **View (3).** This will generate the script code, which you should copy and save.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6357376-1sf5pXBORN6lHO03PsZkUbJyxmMSZCchZ7QhRMzpKsdJgsX48Dee7BgQGLf0oOC5-0/image-20251008144202-1.png)

**Step 2. Add the JavaScript to your website Content Management System.**

This FAQ explains how to insert a chat widget on a WordPress-managed website. The steps are similar for any other content management system like Joomla, Weebly, Drupal, Episerver, Shopify, PrestaShop, etc.

1. Log in to the Administrator panel and go to the section where you can edit or add HTML code. In WordPress, you click on the **Appearance** and **Theme File** **Editor** sections.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6357381-YzeWJzLoRekBOrbLt0dQJrOG0xpIxZyfgCZ5pDM7XTOgDRczI2CQbuFa1WLqIy9u-0/image-20251008144437-2.png)
2. Place the JavaScript into your site header if you want your chat widget to appear on all pages. If you want chat to appear only on a particular page, place JavaScript only in the header part of the selected pages. After you finish editing your site code, click **Update file.

   Note!**The DEFER parameter ensures that this script does not block page loading. The script will run after the page has finished loading.
3. Open your web page or refresh your website if you already have it open. The SuperOffice Chat widget is now available in the bottom right corner of your screen and ready to use.
