# How do I start using forms in SuperOffice CRM?

Updated on 28 Dec 2025

How do I start using forms in SuperOffice CRM?

If you are a SuperOffice CRM Online user, you can start using forms immediately and free-of-charge.

If you have SuperOffice CRM Onsite, you need to have at least version 8.4 to get access to web forms. Check out [this FAQ](https://community.superoffice.com/en/support-faqs/faq/how-do-i-upgrade-superoffice-crm-to-the-latest-version/) to learn how to upgrade your SuperOffice CRM.

**The users of a****ll SuperOffice user plans** can:

- View form submissions that were made available for the groups that a user is a member of.

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465316-W46dL9mz6fx8t0njAiQCAeYyYX6Sc9Yh7UEIfBK7DkL00uDASGcJzExHesCUDpyx-0/image-20251228093828-1.png)
- Process these form submissions.

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465317-nYaSqB3RRckYjfLapYEfQaNRtTjqc2ByBLqLrARhCH1Oz17ghZZdnLA27wlrTeWo-0/image-20251228094051-2.png)
- View all processed form submissions that are stored in a company's or contact’s activity tab.

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465319-xZJ1s2UTW4kbPmQDtTsjf8aXDIUDQiYLWgMssNNHKt4YpYFtSpEEm9DU40RJdigc-0/image-20251228094729-4.png)

The users with the **Marketing** or the **Complete user plan** are also able to:

- Create new and edit forms, as well as create and manage form templates.

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465321-cMBSsUtksrR1WWUoMwHo3kC0k8DDsJsc4PGO1lNLyFDp2neWM5NiaGJw28DzZjfF-0/image-20251228095131-6.png)

  **Note!** The forms created by you can be managed either by everybody (all) or the users of the group you belong to.

![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465322-u1dP1qJdLLqGrNW0zwthHerGChnWInPn4ZpGpxFj98AO9T1S0bai9eTGmM2Huqnb-0/image-20251228095235-7.png)

- View the summary of a form's performance.

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465323-NE8hT9S8lbLfe7Jquh2r42T0bDnc3q6nJYsHHzTPyfaKtOeFmb2HsaAoyXoFXxko-0/image-20251228095702-8.png)
- View a form's report.

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465324-7xetrZownoBPilT1XjtENLJQlisczxpKS5WyrWMH6eEnFn1ZxHcFZ1TSdbG3pPxY-0/image-20251228095846-9.png)
