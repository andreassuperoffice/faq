# What to do when a newly created user cannot log in to SuperOffice CRM?

Updated on 27 Feb 2026

I have created a new user in SuperOffice CRM, but they cannot log in. Why does it happen, and how do I fix it?

There are some known reasons why a newly created user can not log in. The solutions depend on the type of SuperOffice CRM that is used:

- If you use SuperOffice CRM Online, [click this section](https://community.superoffice.com/en/support-faqs/faq/what-to-do-when-a-newly-created-user-cannot-log-in-to-superoffice-crm/#1)
- If you use SuperOffice CRM Onsite,[click this section](https://community.superoffice.com/en/support-faqs/faq/what-to-do-when-a-newly-created-user-cannot-log-in-to-superoffice-crm/#2)

​

**A newly created user cannot log in to SuperOffice Online**

There are two common situations when a new user cannot log in:

1. When a new user was created without an e-mail address, the user name is not an e-mail address, or the e-mail address that has been used is not valid. Please follow the steps below to confirm that the e-mail address is correctly filled in:

1. Log in to [Settings & Maintenance](https://community.superoffice.com/en/support-faqs/faq/how-do-i-access-administration-part-settings--maintenance-in-superoffice-crm/).
2. Click on **Users** (1) and in the list of users select the user who cannot log in (2).

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6560014-Lmo3WQJcklHDn6yX5BGfl8BnJIoQqf8MSpdC5ifCg6F2a4gyn7mmWteskPIt43fq-0/image-20260227125100-1.png)
3. Please make sure that the user has a valid e-mail address filled in because this e-mail address will receive an activation e-mail.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6560026-XF8QWipmTD6FCh0sMxS1X4zq38dBP4HIeNFNt9mwbWwb0wOTEXG75Bhx9l3lBNH6-0/image-20260227125236-2.png)

2. When the new user's account is not activated. Please make sure that the user has received the activation e-mail and that the activation link has been pressed within 48 hours.

![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6560040-NBuarqdeQYQ9X60zf3XMeGu8EdT1dUq8aFLA3qEOxzu70b3QKdDdRHKRkRLGswkI-0/image-20260227125601-4.png)

**Note!** Please make sure that the user has followed the instructions on how to log in to SuperOffice CRM, please refer to [this article](https://docs.superoffice.com/en/learn/getting-started/login.html) for more information.

​

**A newly created user cannot log in to SuperOffice Onsite**

The most common situation when a new user cannot log in is when a SuperOffice licence is properly assigned during the creation process.

If you use SuperOffice 9, please confirm that the user has a licence (1) assigned and **Can log in** (2) toggle is enabled. If that was in place already, please try to remove the licence, **save** (3) the user. Then give a licence and toggle login again.

![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6560044-XSosFbq8Fe0zgUwjMA7EJDEgW2SYLmfohbolxr1jTku2E77WMa6IzEgyjYJRW5E4-0/image-20260227125732-5.png)

If you use SuperOffice 8, please follow the steps below:

1. Begin by removing a licence. Click on the user (1) who cannot log in, deselect the **Active user** (2), and click on the **Save** button (3).

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.exe/getAttachment/4207856-dQjgfKP4AaLlFz58auErpPN75lI8UqSLNpzZyj06E6YDbfqTOKmQkTgzGxgxKmmz-0/image.png)
2. Then, again, assign the licence. Make sure that the same user is selected (1), then add a tick next to **Active user** (2), select the user license from the right side list (3), and click **Save** (4).

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.exe/getAttachment/4207865-JKa97sT4uoC0Ciuc9Bw6bz5cKH3RZh8HRjydeiMGWa4gIUBmjtwpuj9sGxpMewAg-0/image.png)
