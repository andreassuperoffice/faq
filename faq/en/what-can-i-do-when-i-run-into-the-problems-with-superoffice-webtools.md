# What can I do when I run into the problems with SuperOffice WebTools?

Updated on 20 Mar 2026

What can I do when I run into the problems with SuperOffice WebTools?

The SuperOffice WebTools application has a slightly different feature set on Windows and macOS; therefore, the most common SuperOffice WebTools issues are organized into different sections by OS and component.

Please read [this FAQ](https://community.superoffice.com/en/support-faqs/faq/what-is-superoffice-webtools-and-what-does-it-do/) to learn more about the SuperOffice WebTools application.

**SuperOffice WebTools for Windows**

**Troubleshooting WebTools installation**

- Check [this FAQ](https://community.superoffice.com/en/support-faqs/faq/what-to-do-when-i-get-an-error-installation-failed-while-installing-superoffice-webtools-or-maillink-applications/) when you get an error*"Installation failed"*when installing WebTools.
- [How do I enable WebTools diagnostics?](https://docs.superoffice.com/en/document/webtools/troubleshooting.html)
- [How do I reinstall SuperOffice WebTools?](https://community.superoffice.com/en/support-faqs/faq/how-do-i-reinstall-superoffice-webtools/) **Note!** Do not follow this FAQ in a Terminal server/Citrix environment

**Troubleshooting Web Extensions features**

**Document and e-mail creating, opening, locking, editing, and saving**

- Check [this FAQ](https://community.superoffice.com/en/support-faqs/faq/what-to-do-when-i-get-an-error-unable-to-cast-com-object....-when-opening-an-e-mail-from-superoffice-crm) when you get an error "*Unable to cast COM object of type 'Microsoft.Office.Interop.Outlook.ApplicationClass' to interface type 'Microsoft.Office.Interop.Outlook.\_Application'...."*
- Check [this FAQ](https://community.superoffice.com/en/support-faqs/faq/what-to-do-when-an-outlook-e-mail-dialog-does-not-open-after-clicking-on-an-e-mail-address-in-superoffice-crm/) if the new Outlook e-mail dialog does not open after clickin on an e-mail address in SuperOffice

- Check [this FAQ](https://community.superoffice.com/en/support-faqs/faq/what-to-do-when-my-documents-and-e-mails-get-opened-on-my-colleagues-instead-of-my-own-computer-and-how-to-fix-it/) when you use WebTools and your documents are opened on another computer.
- Check [this FAQ](https://community.superoffice.com/en/support-faqs/faq/what-do-i-do-when-i-get-a-notification-that-another-person-is-editing-the-document-that-i-try-to-open-it-in-my-superoffice-crm/) when your colleague locks the document you try to open.
