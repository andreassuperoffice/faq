# How do I create a new SuperOffice user from Active Directory user?

Updated on 27 Feb 2026

I would like to create a new SuperOffice user who could use Active Directory authentication. How do I do it?

To create or, in other words, import a user from an Active Directory (AD) to SuperOffice CRM, please follow the steps below:

1. Log in to [Settings and maintenance](https://community.superoffice.com/en/support-faqs/faq/how-do-i-access-administration-part-settings--maintenance-in-superoffice-crm/), then **Users**.
2. Select the **Associates** (1)tab. Click on the **+Add** (2) button. Then click on the ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6559921-kQriONKjXPo4ujKLcWBwzw94ab60y7OLbwSaqfl3yp8jrOaNkMoCI5HcSuGTALUR-0/image-20260227121450-2.png) (3) icon and select **Active Directory (Windows), which is responsible for the user name and password** (4).

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6559920-ffMhyB7Q6lAbreETsKcJe3wnrC8ZnokzrO6Ha7PAszBMPRBf5H1sEunlwYMZo4D7-0/image-20260227121312-1.png)

   **Note!** If more than one company works on the same database, then you also need to select the company for the user (5).

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6559946-izKgCcRQ3aYWGrDG5aFuFgjUYZKHklwQwdGJcjgyjag4jnROOIf3lKPYLXkWYoX5-0/image-20260227122008-3.png)
3. Then **Click here to select an AD user.**

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6559954-zx2ZRsh93RcUMNM24K9MC1rRCIRDQAqliFFDyBcZn4bwBlQpCMgQUFUnoTYhbgxD-0/image-20260227122424-4.png)
4. Click on **Find**(1) and the list of Potential users will show up, select the user/users you want to add, and click **OK.**

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6559962-AmUCFNIe6y3I3cODXma3ZXmkqOhqQeELwX6F3zXiGd7BnjNnwA3kY2pz5cpPoxR6-0/image-20260227122549-5.png)
5. Fill in the rest of the fields that are not populated automatically. If you need help, you can check [this FAQ](https://community.superoffice.com/en/support-faqs/faq/how-do-i-create-a-new-user-group-in-superoffice-crm/).
