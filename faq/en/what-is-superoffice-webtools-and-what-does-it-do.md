# What is "SuperOffice WebTools" and what does it do?

Updated on 24 Jul 2026

When working in SuperOffice CRM, you may be asked to install, start, or update SuperOffice WebTools. What is SuperOffice WebTools, and what does it do?

SuperOffice WebTools is a set of small programs installed on your computer. It makes it possible to open, edit, save, and upload documents from SuperOffice CRM, display diary notifications, and open context-specific links in SuperOffice CRM. The functionality of SuperOffice WebTools depends on whether you use it on Windows or Mac:

- [Click here to read more about SuperOffice WebTools on Windows](https://community.superoffice.com/en/support-faqs/faq/what-is-superoffice-webtools-and-what-does-it-do/#t1)
- [Click here to read more about SuperOffice WebTools on Mac](https://community.superoffice.com/en/support-faqs/faq/what-is-superoffice-webtools-and-what-does-it-do/#t2)

**SuperOffice WebTools for Windows**

On Windows computers, SuperOffice WebTools installs Web Extensions. Web Extensions is the SuperOffice toolbar application, also known as the TrayApp. You can access it by double-clicking the SuperOffice CRM Owl in the Windows notification area.

![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6793234-MBPOtg8uxoYG43BFAsMiUxjKwT508I6NnHmYl7AXwaRiQjN6fw3iSDgKuLF9jiqU-0/image-20260724085009-1.png)

**Web Extensions** is responsible for:

1. Automatic downloading, locking, saving editions, and uploading of the documents from SuperOffice CRM.
2. Displaying diary notifications (alarms).
3. Enabling you to automatically log in (1) to your SuperOffice CRM from the Toolbar application (see in the screenshot above). This will open a new browser tab.
4. Enabling the use and opening of SO Protocols by opening a context-specific SuperOffice CRM website after clicking on a SoProtocol (*superoffice://…*) link in mail addresses, etc. Read more about SO protocols in [Docs](https://docs.superoffice.com/en/ui/soprotocol/index.html).

**SuperOffice WebTools for Mac**

WebTools for Mac is an application that you can access by double-clicking on SuperOffice Owl in your Toolbar.

![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6793238-NCIGb8WK1fhrQwGmor3ZBlnDJzmG9SLGQFh0fbAlLju2qfPseWmYT293z4F1NsZP-0/image-20260724085125-2.png)

WebTools for Mac are responsible for:

1. Automatic downloading, uploading, and locking of the documents from SuperOffice CRM.
2. Displaying diary notifications.
3. Enabling you to automatically login (1) to your SuperOffice CRM from the Toolbar application (see in the screenshot above). This will open a new browser tab.
4. [Allowing to copy SuperOffice appointment to Calendar on Mac](https://community.superoffice.com/en/support-faqs/faq/how-can-i-copy-superoffice-contacts-over-to-my-mac-contacts-or-appointments-to-mac-ical-calendar/).
5. [Allowing to copy SuperOffice contacts to Contacts on Mac](https://community.superoffice.com/en/support-faqs/faq/how-can-i-copy-superoffice-contacts-over-to-my-mac-contacts-or-appointments-to-mac-ical-calendar/).

**Note!**

- From WebTools version 13.2.3, used together with SuperOffice version 11.11 or newer, MailLink is no longer included in the default WebTools installation due to changes in Outlook support for COM add-ins. If you use Windows and still need MailLink, it can be installed separately. For more information, see [this FAQ](https://community.superoffice.com/en/support-faqs/faq/why-is-maillink-not-installed-when-i-download-webtools/). Alternatively, we recommend using [SuperOffice for Outlook](https://docs.superoffice.com/integrations/superoffice-for-outlook/index.html), which provides a modern integration with Outlook.
- MailLink is not available for Mac. If you use a Mac, we recommend using [SuperOffice Inbox](https://community.superoffice.com/en/support-faqs/faq/how-do-i-start-using-the-superoffice-inbox/) or [SuperOffice for Outlook](https://docs.superoffice.com/integrations/superoffice-for-outlook/index.html).
