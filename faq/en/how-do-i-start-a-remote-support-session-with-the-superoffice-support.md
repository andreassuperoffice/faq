# How do I start a remote support session with the SuperOffice Support?

Updated on 5 Jan 2026

How do I start a remote support session with the SuperOffice Support?

To start a remote support session, you will receive an email from a SuperOffice Support Consultant containing a remote support session link. The link will look similar to this example: [https://quicksupport.me/sxxxxxxxxx](http://quicksupport.me).

Please choose the instructions for your operating system:

- If you use Windows, [click here](https://community.superoffice.com/en/support-faqs/faq/how-do-i-start-a-remote-support-session-with-the-superoffice-support/#t1)
- If you use macOS, [click here](https://community.superoffice.com/en/support-faqs/faq/how-do-i-start-a-remote-support-session-with-the-superoffice-support/#t2)

**For Windows ​**

**Note!** The screenshots shown are from Google Chrome and may look different in other browsers.

1. You will see a screen with two options. Select Windows to download the application to your computer.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465401-frZDFQkp3Y7p5swJzsiahuf0d493THAM7PJphIDMkNtcGjSJAPx5eDlGd6a1nQjE-0/image-20251228183433-5.png)
2. Click on the downloadedTeamViewer application to start it.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465402-JKr5xcii5xABCaBe6Ssu5wyw43MCR3blYSjIO0JS8RhPkdsm6BiZijklYQb6NjIT-0/image-20251228183457-6.png)
3. Accept the End User License Agreement and the Data Processing Agreement, then click Continue.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465403-t2N9pOC4bYulsRw9DSHsyRhxE6UG9Q91mgfHT8CxSs7ON7s24Y6cE7pDggAdPTfq-0/image-20251228183616-7.png)
4. It may take a few minutes for the connection to be established.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465404-3jx2Stwo6cjzJ1lKfFXIq3cKQkHDZC5C5TH6TQ0WGb7Ko8fwIUOSEqt5CJRgk5RE-0/image-20251228183739-8.png)
5. When prompted, click **Allow access** to start the session.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465405-922hDkZ1sWIh8ilmxTEZE2ggIYUxmxwAG7AZUzptL9m3psJyqn2k48q8wQoKIYnt-0/image-20251228183830-9.png)

**​For macOS**

1. You will see a screen with two options. Select macOS to download the application to your computer.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6466668-Xu7jX4dTZXPcmUzSsBmHwJJqYTQNClqt2DHoTC177xWwfcKmXbY8MJg5UFwdm5dP-0/image-20251230130932-1.png)
2. If prompted, allow downloads from *quicksupport.me* to proceed.
3. Navigate to the **Downloads** folder. Locate the downloaded **TeamViewer** application and double-click it to start.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6466690-wXQ9nhbd2nGN2q4BdgkOcjWxmXOKa0XXuTwb1NTaFGFm0DlQ7UcENx6iR5JhQjhm-0/image-20251230132656-6.png)
4. Accept the End User License Agreement and the Data Processing Agreement, then click Continue.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6466779-GEXnlO7kiO0bQmOMWrYB5yWkRxIDjT0ipoN5aLhfSCyPtIpX3ugp390mbF05Nqfc-0/image-20251230150536-1.png)
5. If it's the first time having a TeamViewer session, you will need to grant access to your device. Please refer to [this article](https://www.teamviewer.com/en/global/support/knowledge-base/teamviewer-remote/remote-control/remote-control-a-mac/) for more information.
6. It may take a few minutes for the connection to be established.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6466793-mYBXpR81IZZXOE27UsC7iCACcgpKI9AK0zRD9Hp95KEemA9P6keiqJ54xTHzyYyg-0/image-20251230152629-2.png)
7. When prompted, click **Allow access** to start the session.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6466794-ZAyXMD4yKtylHIqQ3lGB448nkj8WwnHOMSANnCH55KAOwErZCHyi5qAQ6b1JloX5-0/image-20251230152751-3.png)

**Troubleshooting**

If the remote session does not start:

1. Make sure the TeamViewer application has been opened as described above.
2. If the session still doesn’t start, check that no other TeamViewer instance is running. **For Windows**, you can close it via Task Manager:
   - Right-click the taskbar and open **Task Manager**
   - Find **TeamViewer** in the list
   - Select it and click **End task**

     ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465406-ZlCaK4RhR0zxjn1LBsuaq88Gcddx0N7PZ93fE3qGSK5SwRkhOYGKJLygapu411mJ-0/image-20251228185645-10.png)

     **For macOS**
   - Right-click (or Control-click) the **TeamViewer icon** in the Dock.
   - Select **Exit TeamViewer**

     ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6466688-PMPrHwNF34DS6d6PppFfLd4wlxHQdxKq4GNM4Qdg8U6LgSx4RtT8ZQbkTOZuLEUT-0/image-20251230132137-4.png)

**Not****e!** If you click the **Close**button, the remote session will be closed, and you will need to restart the process from the beginning.

![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6466689-4Nffokg0sJ7NqLR8j5tK17pdUGJCZ2T1y8BEmx2BsBqMgHkjfzu1txKYZRX7puO9-0/image-20251230132242-5.png)
