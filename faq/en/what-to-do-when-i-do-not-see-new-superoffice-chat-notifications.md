# What to do when I do not see new SuperOffice Chat notifications?

Updated on 24 Jul 2025

We’ve enabled the **Warning on new chat message** setting in the **SuperOffice Chat** channel properties, but we’re not receiving notifications. Why is this happening, and how can we fix it?
![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6275368-SOwbUPUSYO0CWFX9d5Mga8psOLZPUtw6d492FiNyY6ltTHRJ30DXM4mjWIaeDB8D-0/image-20250724120716-1.png)

There are a few things that you need to double-check if you cannot see chat notifications:

1. [Your SuperOffice Settings](https://community.superoffice.com/en/support-faqs/faq/what-to-do-when-i-do-not-see-new-superoffice-chat-notifications/#1)
2. [Your Internet Browser's Settings](https://community.superoffice.com/en/support-faqs/faq/what-to-do-when-i-do-not-see-new-superoffice-chat-notifications/#2)
3. [Your Windows Notification Settings](https://community.superoffice.com/en/support-faqs/faq/what-to-do-when-i-do-not-see-new-superoffice-chat-notifications/#3)

​

**Your SuperOffice Settings**

1. Notifications about incoming chats will only appear if your status is set to **Present**. If your status is **Away**, you will not receive chat notifications.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6275369-ksQDuOq1FZA02GNA9RcHotwT4m85LdYxajmnPdFexpxwOHbGujTZlKT7Jg8Sfy7m-0/image-20250724121432-2.png)
2. Make sure you have **enabled notifications for new chat messages** in your **SuperOffice notification settings**. If this option is not selected, chat notifications will not appear even if your status is **Present**.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6275455-Iok9qPre4iL2KODrbcEQtRtQk2Sj859n3bFc0kxiP5OsDWBSnXn6cJC4UNGnBAcz-0/image-20250724141806-1.png)

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6275456-sUTtrGB5sQr4fA01MHhctQnxy8x4xK2KzUtmBZmhsgyKxD0E1oJad3ZueZDMJZTy-0/image-20250724141827-2.png)
3. To get a chat notification sound, you need to have **Enable sounds** preference set to **Yes** in your **Preferences**.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6275370-WhcqmWqHL7mHHY0PPLb6qLt3KxIgqErpWTjLuQyWXpf0O7SkPZkmDidOfNE6ZqDs-0/image-20250724121533-3.png)

**Your Internet Browser's Settings**

To see notifications, make sure your browser isn’t blocking notifications. Let’s take a look at how to check these settings in Microsoft Edge — the same process also applies to Google Chrome.

1. Click the **View site information** icon next to the SuperOffice URL in your browser. Make sure that Notifications are set to **Allow**.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6275413-wRIJ3OX5x8y4Ri2481TLA3l2nkBOf1TZGGJu51jjPgcC0XAHdn7JfRX5e12Iu6iF-0/image-20250724131324-11.png)
2. Check if the SuperOffice website is in the block list for notifications.

   In **Edge**, go to: [edge://settings/content/notifications](http://edge://settings/content/notifications);
   In **Chrome**, go to: [chrome://settings/content/notifications](http://chrome://settings/content/notifications).

   If SuperOffice is listed under **Blocked** (or **Not allowed to send notifications** in Google Chrome), remove it to allow notifications.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6275372-n2ZlM1T9EqKUMxRlypf1d0LgRojS3mDgoy0HXWMm00BFFmahCnMJ1at8deYlPXwf-0/image-20250724123001-5.png)

​
**Your Windows Notification Settings**

Windows **Notifications & actions** settings must be enabled on the computer for notifications to work. Please follow the steps below to see where these settings are stored in a Windows 11 system:

1. In global search type in **Notifications and actions** (1) and click on the **System settings** (2) option.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6275376-oygmBmGj9whn4Gh4Ayp4lH5xiJyHEych5LdS6dOuCgtuhtECNA2sNAAMnNOkb0Xt-0/image-20250724123702-6.png)
2. Make sure that **Notifications** are set to **On** (1) and **Do not disturb** is set to **Off** (2).

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6275377-FcU0pmFl4ycWYoOCmwBopYJgZIKUr6UmFMQbqFdWZB3m8w06YQoQSir411Gw4R1a-0/image-20250724124021-7.png)

**Note!** Make sure Focus mode is turned off, as it can block chat notifications. [This article](http://support.microsoft.com/en-us/windows/make-it-easier-to-focus-on-tasks-0d259fd9-e9d0-702c-c027-007f0e78eaf2) explains how to disable it. Alternatively, you can add SuperOffice chat to your priority applications list - [this article](http://umatechnology.org/how-to-enable-use-focus-assist-in-windows-11-to-control-notifications/) explains how to do it.

**Known Problem if SuperOffice Website is Installed as an Edge Application**

If you have the SuperOffice website installed as an Edge application but still open SuperOffice in the browser, notifications will not be shown. To fix this, you need to uninstall the SuperOffice Edge application.

1. Click the **View site information** icon next to the SuperOffice URL in your browser. Then click on **Permissions for this site**.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6275400-P3EDIdhTyQqF0KINNk5fB74GLAbZ9c2tIOZKody4YwTKMwQIBU5aZhqlwpo2PKiT-0/image-20250724130239-10.png)
2. If the window shown below appears, it means the SuperOffice website is installed as an app. In this window, you can uninstall it by clicking **Uninstall**to remove the app version.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6275421-TkN1Mi8reiWdXP46eYb3k2WKQpsoZyrFf0576LEAIkDKmXUYjrRKt42edPZPsZue-0/image-20250724132343-14.png)

**Run a Notification Test (Advanced Users Only)**

If you would like to test notifications, you can paste the following code into your browser’s Developer Tools console at your own risk. This is an example script intended for testing purposes only.

1. Make sure you are on the SuperOffice website - not any other site.
2. Click on Settings and more (the **three-dot menu**), then go to **More tools** > **Developer tools**.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6275427-WgFcR3xhUPesRlcwghzIKuM85oxof3CPXDagNPgs1Ppfiu0u1dEc7US0EAJBZQBU-0/image-20250724133302-17.png)
3. Paste code below into Developer Tools - **Console** and press **Enter**.

   if (!("Notification" in window)) {
     console.log("❌ Notifications not supported.");
   } else if (Notification.permission === "granted") {
     new Notification("✅ Notifications are working!");
   } else if (Notification.permission === "denied") {
     console.log("🚫 Notifications are blocked for this site.");
   } else {
     Notification.requestPermission().then(permission => {
       if (permission === "granted") {
         new Notification("✅ Notifications are now enabled!");
       } else {
         console.log("❌ Permission was not granted.");
       }
     });
   }
4. If everything is set up correctly, a notification like the one shown in the screenshot below should pop up.
