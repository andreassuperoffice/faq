# How do I configure my settings that all e-mails I send would get archived to SuperOffice CRM automatically?

Updated on 12 Jan 2026

I am using Outlook to send all my e-mails. I have SuperOffice WebTools (MailLink) installed, and I can manually click on the archiving button to get all e-mails archived to SuperOffice. Is there a way to make all sent e-mails archived to SuperOffice CRM automatically?

SuperOffice MailLink settings allow you to set up so that all outgoing e-mails will get archived to SuperOffice automatically. Please follow the instructions below to do it:

1. In Outlook, click on the arrow icon in the SuperOffice Ribbon. If you cannot see the SuperOffice Ribbon, please check [this FAQ](https://community.superoffice.com/en/support-faqs/faq/what-to-do-when-superoffice-archiving-button-has-disappeared-from-outlook/).

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6479510-BEDRJa5ZgpfMxhThuKsbHgMcKKKFOShdhoReJQZb39JygOJb8FohMAfKzMiWuFsz-0/image-20260112201803-1.png)
2. The pop-up dialog with archiving options appears. There, you can set up the cases in which e-mails should be automatically archived. In the sections below, it is illustrated which e-mails will automatically be archived to SuperOffice when archiving options are selected.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6479511-NuWrNIXJ9Wm1NC35lFAJEC1MszbaWRlYxbECwGZaoJGnP7gSrQ8EZzQjOgyPbs71-0/image-20260112201927-2.png)
   1. **Created from SuperOffice CRM.** All e-mails, which are going to be created in SuperOffice by clicking on the e-mail address (2,3), clicking on the **E-mail** button (1), and right-clicking on Contact and selecting the option **Send e-mail**(4), will be archived automatically when this option is marked.

      ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6479518-hP1foIlSRR6P76m83wqsW4LGaXqEL6ZWuwdeH9GGmfTHSdFwAFod6DqxXCNDhDLw-0/image-20260112204250-9.png)

      ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6479519-heZQP8fXuNGPkoIGnHrK6lCWBwLrXzr5tGYWE2oK9OWou77CJFFpATqAHNo88akK-0/image-20260112204559-10.png)
   2. **Written to associates from SuperOffice CRM.** All e-mails, which are going to be created in SuperOffice by clicking on the associate's e-mail address (1) or right-clicking on **Contact** and selecting the option **Send e-mail** (2), will be archived automatically when this option is marked.

      ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6479516-OcdbzMStLNQY6rtwyJYXmJXS1RQ4OQdaTYukNOTBwgWocfhGxyaCB7iu1Rjqk0Ux-0/image-20260112203553-7.png)
   3. **Created from the e-mail client.** All e-mails, which are going to be created in Outlook by clicking on the **New e-mail** (1) button or created by clicking on Reply, Reply All, Forward (2), will be archived automatically when this option is marked.

      ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6479515-9z2Mzg2yH5Z6PTADwbco6phiskKCUs0tR7FqAHL3NASKBTTcQIFGExzrSfE8aeBw-0/image-20260112203121-6.png)
   4. **Replying to e-mails from SuperOffice CRM.** All e-mails, which are going to be created in SuperOffice CRM by right-clicking on the archived e-mail and clicking on the **Reply** option, will be archived automatically when this option is marked.

      ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6479514-PjXFqwd2GCKMDxYf8l34pO8yPg2HhK9SnPckAQJAzqRr4KcwQkduYWnmp1RMkEcD-0/image-20260112202857-5.png)
   5. **Forwarding e-mails from SuperOffice CRM**. All e-mails, which are going to be created in SuperOffice CRM by right-clicking on the archived e-mail and clicking on the **Forward** option, will be archived automatically when this option is marked.

      ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6479513-2xzIKZASldSpaD4p6n1K5htdKQ9yjdWnzOr46eGt8klfJnXdL88dL8EhzeUMYn2n-0/image-20260112202753-4.png)
   6. **Sending appointments from SuperOffice CRM.** All e-mails, which are going to be created in SuperOffice CRM by creating an appointment and selecting the option that sends e-mail invitations to appointment participants, will be archived automatically when this option is marked.

      ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6479517-dGaGnt2e7Ty3PwuKxWA0QMLR7bEGEhShRhbNXncTqELkGusoOrqYO5dwG1MP3Srj-0/image-20260112203736-8.png)
   7. **Sending documents from SuperOffice CRM.** All e-mails, which are going to be created in SuperOffice by selecting a document and right-clicking it, and by choosing the option **Send as e-mail,** will be archived automatically when this option is marked.

      ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6479512-oRe6D5zNKkjB3Icg0cabCjFABCLhuJiS03NKAXnFKlscX5MQHwyg2Z1ejTdSSEU1-0/image-20260112202648-3.png)
