# How do I start using CRMScript in SuperOffice Online?

Updated on 27 Nov 2025

How do I start using CRMScript in SuperOffice Online?

To be able to use SuperOffice CRMScript, please make sure:

- Your SuperOffice installation has a Development tools license. To confirm it, log in to [Settings and Maintenance](https://community.superoffice.com/en/support-faqs/faq/how-do-i-access-administration-part-settings--maintenance-in-superoffice-crm/), click on **Licences (1),**then the **SuperOffice (2)**tab, and in the System licence section, locate **SuperOffice Developer Tools (3)** licence. If you cannot find it, but you need it, please click on the **Purchase new licences** **(4)** button.

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6420471-D4uA1DQeGCYmszuk31YrdmCh6rWsCY4K7ijZK7FfoXdUN5yOrBHm2NRfol62aMXf-0/image-20251127144958-1.png)
- Your SuperOffice user has a **General Administrator** functional right assigned to the role, which is set for the user.

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6420486-soUl6NDU0U1kzuiwTqOwkakQBkZ0HuOLZoUfaWtPetjyL9rKNjNHYnRGyr9FJi8z-0/image-20251127145153-2.png)

**Note!**

1. Scripts, Macros, Event Handlers, and Scheduled tasks can be created for you by a SuperOffice Consultant.

2. All support questions related to Scripts and SuperOffice SDK need to be posted in [SuperOffice Community Forum](https://community.superoffice.com/en/technical/forums/).
