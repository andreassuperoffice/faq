# What is the difference between the fields in SuperOffice Forms?

Updated on 3 Jan 2026

What is the difference between the fields in SuperOffice Forms?

IntheField section in SuperOffice Forms,after clicking to add a new field Add element dialog opens, where you can choose between **SuperOffice (1)**, **Form (2),** and **View (3)** elements. These sections contain different types of fields that you can use in your forms.

![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6467858-anCjgAn6ZIFHxnrky3X2nannfSFX53z2SsMGZTU6eWk98hgwJZieEh0PHSob86my-0/image-20260103111503-1.png)

**SuperOffice elements**

SuperOffice elements are standard fields in SuperOffice CRM. The information submitted via these fields updates the corresponding fields in your SuperOffice CRM.

![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6467859-5hyyLDbYg6mBjZ5F2nI04cbWgfjOl4dSo1fJbIH509IFtMhPBYp1akUTcLF0uN0Q-0/image-20260103111953-2.png)

**Form elements**

Form elements are generic fields that can be used in your form. Here are some useful tips on how these fields work.

![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6467864-BDeC72E5gm39UFGjNgXGelDA7Ms7uk4wXafTk9IqThsFYC5N09Ke1T1qhgikx8o7-0/image-20260103120144-7.png)

- **The Text field** allows you to collect short replies. If the input is longer, it is recommended to use the **Text area** field.
- Results of the **Radio buttons,**the **Check boxes,** and the **Drop-down** fields are visually summarized in a form’s **Reports** section.
- The **Hidden** field – allows you to set a default value for the field (1) that is not visible for respondents. For example, this field can let you know where the form was filled out.

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6467866-HszBeHWQOJhFEsaHMxu72hsl6PDL1gfhnjRZ5UNTDoA1bn5gSjDlhe8btA6i6Ngr-0/image-20260103122152-9.png)

  If the form in the **Actions (1)** section has the option **Notify of submissions by creating requests (2)** selected, the automatically created request will have the line (3) with the default value that is set in the field.

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6467867-DZFmHQZOHoOaEaxopm8uMDMXJUIIw4BwX8qwtBRFoLLKfXcearwMajRfyaZmk0Ym-0/image-20260103122328-10.png)

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6467868-pelW2n8IH8AhM0hfs40i76ozdNm55fnrDlz9OJznjcbfMmHbqLnKLmYXx4zAaAHn-0/image-20260103122520-11.png)
- The **Upload file** is a fieldfor uploading files:
  - **Allow multiple files:** Select this option to allow multiple files to be uploaded.
  - **Maximum file size (kb):** Enter a file size in kilobytes to prevent a large file from being uploaded. Leave this field empty to allow all file sizes.
  - **Allowed file types:** Enter the file types that can be uploaded. Use the format jpg, gif, png, bmp (comma-separated, no space). Leave this field empty to allow all file types.
- The **Rating** field allows you to use different rating scales. Currently, you can choose from stars, dice, thumbs, smiley, and NPS.
- **Google reCAPTCHA** is a free Google service that will ensure that only real users can send in web forms. This prevents spam and automated bots from sabotaging your data collection**. Only one** field of this type is allowed in the form.
- The **Date** and **Date and time** fields are used to store dates and times.
- The **Integer** field is used for whole numbers (positive, negative, or zero) without a fractional or decimal part (e.g., -3, 0, 5). In contrast, the **Decimal** field is used for numbers that include digits after a decimal point, representing a fraction or part of a whole (e.g., 0.5, 3.14, -1.2).

View elements allow you to include a section, image, and text to visualize your form.
