# How do I change a type of a user-defined field, which I created before?

Updated on 30 Dec 2025

I have created a user-defined field with type *Short text,* and I would like to change it to *Long text;* however, I don't see this option in the drop-down list. Why does it happen, and how do I fix it?

![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4395303-2PRF9fjsNWWAQ4DHUHPP3I8OCAgmTyAMbDiL5FazkQOMo4g9JkGSPUwBYC787O9S-0/image.png)

It is not always possible to change the user-defined field type to any other field type that you want. Different types of user-defined field values are stored in different tables in the database; therefore, not all conversions are possible.

In SuperOffice, you have 8 different types of user-defined fields: *Number, Short text, Long text, Date, Unlimited date, Checkbox, List, and Decimal.*

![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6370118-3gEyjuIroWCrCl652Puo1WdhDjcfBq9BMlO5rJaCXNdYgumdfmO76q7Q9gDYsOmJ-0/image-20251020193656-1.png)

- Field type **Number** can be changed to **Short text** and **Decimal**

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6370123-YLoh6EO0WKbi5SgMXl3XGB26Y90HjJlRsUQXt1NiElH8hBi1tzNoJDtEZpYQ8tgP-0/image-20251020194303-6.png)
- Field type **Long text**cannot be changed to any other field type.

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6370120-UBK2o41EC2iEumRrnxjQ3YNLd7fzggAeL8l7gazQa9cNOAhFxM5AwwyXtjNiN1qF-0/image-20251020194021-3.png)
- Field type **List**can be changed to **Short text.**

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6370121-ndMJ3y5QasCHJRRnMMRa2iRKjKdclIzI47zcRtQ3OtEtrJAtPsLtm3Qk9IpeOWmS-0/image-20251020194128-4.png)
- Field type**Short text​**can be changed to **Number.**

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6370122-754UikJB8KUKMC69eHKj5XFWqnxP26wCMODYIR7CCbWf6yHAw5K0hzncTznJPj80-0/image-20251020194210-5.png)
- Field type**Date**can be changed to **Short text** and **Unlimited date.**

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6370124-JH4desCl0jsAy4W4fs6PS1qBZbA2XtbOllwxy6pMCjiMg7Q65fwJ0Qfeu00HKhUg-0/image-20251020194359-7.png)
- Field type**Unlimited date**can be changed to **Short text.**

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6370127-chnEeG0H5b4x4YHf1TcCpuC8C4FnaKo0Uzot96ST35yA8pql6rBHcA3UTI02fdyM-0/image-20251020194554-8.png)
- Field type**Checkbox**can be changed to **Short text.**

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6370128-AgEubOBKlETAFUZax0pGKTfa2pBDx5bkNQ06De7pHAaSNYo9qm3FdI5XypQQpklZ-0/image-20251020194653-9.png)
- Field type**Decimal** can be changed to **Short text** and **Number.**

  ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6370129-Q2DDjlbh62usFWCMet77aKicWSDpDMg5u6H5LdnelnPx0zRZZxpyXGL09jBKwe8G-0/image-20251020194906-10.png)
