# What to do when I get an error (null)://(null)/ in Mac Web Tools login screen?

Updated on 23 Mar 2022

I get a SuperOffice Web Tools login dialog on my Mac. Instead of my company’s SuperOffice Online URL, I see a notification *(null)://(null)/*

How do I connect SuperOffice Web Tools to my SuperOffice installation?

![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/3704977-YD7jdjzbRiNS3n84ueUjGxbeaLNq1jegFRrzcco3NYyyNhPQtQsj7Q5o7Ca9iO1T-0/image.png)

To be able to configure SuperOffice Web Tools, please follow the steps below:

1. Open the **Preference** dialog of SuperOffice Web Tools, find the setting, which has *(null)://(null)/* URL and delete it.

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4638133-i6sy0D758M7Hsk7N8Yi8bDK5Zul7Esgjx7aRqx3OboFTN3HrMsSey5W5o9RWktWW-0/image.png)
2. If this did not help, then open a **Finder** application, type in the word *~/library* and open it.

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/3704993-BhGjt5IpdkMS1Ro7eeYaiH2wFSqNNqTWykJxOs9EMU4TNTa788A6zFxxdFtsJC5o-0/image.png)
3. In the folder list find the folder called **SuperOffice Web tools** and delete it.
4. In the top menu click on the ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4333792-EmGXAHWfM7ZGtdKnZJHTLWSPHnetJGrdgXz1lZ9mlMoMCdqb0f6aLENfxqX43xEA-0/image.png) button, then click **Download**and select **SuperOffice Web Tools.**

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4333791-rcbcdGOcg9eLe192gqKU1IHz2c0LfwJBuOtSILtQx4WpDCsXnFLGl3RP3qxwT2nK-0/image.png)
5. In the new dialog choose**Personal computer Home/office** **(1)** and click **Next (2).**

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4333797-Hgx3gLFz6UtHgXnXtxO2gNesLF71eYAAiNN2PwLizqiucB5isLpWNAuK6hxrJlKz-0/image.png)
6. In the next screen, click on the link **Click here to connect Web Tools to this SuperOffice installation.**

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4638137-x4376Z4BYyBDt9a3NRdp47nLlwmiczMwQu9UMr3jxo6QiUCzklhjFkARLbwmTpw6-0/image.png)
7. This action will download a configuration file to your computer.

   ![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/3705008-LnJhhfbMJLmRDDdsURAH4ThK4dX8XHxUioz1HmXMOlCHggrWA2SUfE5eTAcNH7XT-0/image.png)
8. Double-click on the *.SoConfig* file and it will connect Web Tools to your installation.
