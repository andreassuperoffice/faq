# How do I use SuperOffice CRM template variables to automatically insert information into a document?

Updated on 15 May 2026

How do I use template variables to automatically insert information from SuperOffice into a document template?

To be able to use information from SuperOffice CRM in the documents, which you generate from SuperOffice, you need create a document template with template variables. Please check [this FAQ](https://community.superoffice.com/en/support-faqs/faq/how-do-i-upload-and-use-document-templates-in-superoffice-crm/) to learn how to create a new document template. To find a list of all template variables that can be used in documents check [this article](https://docs.superoffice.com/en/document/templates/learn/template-variables.html).

For you to succeed when creating and using document template with variables, we want to share with you some tips:

1. When you are typing in a template variable in the new document, we recommend to start by creating brackets {} and then inserting a variable text inside the brackets.
2. When you want your document template insert an information from the fields, which you created in SuperOffice CRM yourself, you will have to find a variable name first.

   To find the variable open [Settings and Maintenance](https://community.superoffice.com/en/support-faqs/faq/how-do-i-access-administration-part-settings--maintenance-in-superoffice-crm/), then click on **Fields (1)** and choose the tab where field was created (2). Then find the field name in the list (3) and double-click to open it.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6275515-tuZpHF4UseqTWOJhw2tkIEp2imzZYIXisxySR138lP6QDWyupWEkmBXUiU7h9INN-0/image-20250724151042-1.png)

   In the bottom of the dialog you'll find the template variable name (4) of the information stored in this field.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6275534-udEYUCHxwIkfC10gdlQNzh2IoY0aHzdmf5sJplfTalFn67XtF5MaCeJtLSJADDhS-0/image-20250724151215-2.png)

   **Note!** If for some reason template variable does not work, please try to delete it, save the document. Then open the document and type in the template variable again.
