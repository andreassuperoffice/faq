# How do I reassign a SuperOffice licence from an old user to a new one?

Updated on 11 Aug 2026

One of our colleagues has left the company. We would like to reassign her SuperOffice licence to a new person. What is the best way to do it?

Please follow the steps below to learn how to reassign a SuperOffice license from an old user to a new user in SuperOffice:

1. Remove the license from the old user by toggling **Can log in (1)** option in the old user card. This will automatically remove a **User plan (2)** and make it available to a new user.

   **Note!**To keep an overview of all historical activity of old users, we do not recommend deleting them. If you want to reassign all the companies, open sales, projects, and tasks from the old to a new user, check [this FAQ](https://community.superoffice.com/en/support-faqs/faq/how-do-i-reassign-all-accounts-companies-contacts-and-open-tasks-sales-projects-from-a-person-who-left-the-company-to-a-new-person-in-superoffice-crm/).

2. Create a SuperOffice user for a new person in your company. Check [this FAQ](https://community.superoffice.com/en/support-faqs/faq/how-do-i-create-a-new-user-in-superoffice-crm2/) to learn how to do it.
