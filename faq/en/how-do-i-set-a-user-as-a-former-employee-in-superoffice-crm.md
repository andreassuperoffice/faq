# How do I set a user as a former employee in SuperOffice CRM?

Updated on 3 Nov 2025

My colleague has left the company. What is the best way to remove his access to SuperOffice?

There are two ways you can remove a user from SuperOffice CRM:

1. [Remove the license and mark as a former employee](https://community.superoffice.com/en/support-faqs/faq/how-do-i-set-a-user-as-a-former-employee-in-superoffice-crm/#1)
2. [Delete the user](https://community.superoffice.com/en/support-faqs/faq/how-do-i-set-a-user-as-a-former-employee-in-superoffice-crm/#2)

If you want to move open activities, sales, etc., from this user to another user to take over, please have a look at this FAQ: [How do I reassign all accounts (companies, contacts) and open tasks, sales, projects from a person who left the company to a new person in SuperOffice CRM?](https://community.superoffice.com/en/support-faqs/faq/how-do-i-reassign-all-accounts-companies-contacts-and-open-tasks-sales-projects-from-a-person-who-left-the-company-to-a-new-person-in-superoffice-crm/)

You should do this before you mark the user as a former employee or delete it, because afterwards, you will not be able to create selections based on this user anymore.

**Note!** You cannot update the owner/author of documents.

​

**Remove the license and mark as a former employee.**

Please follow the steps below:

1. Login to SuperOffice CRM and access [Settings and Maintenance.](https://community.superoffice.com/en/support-faqs/faq/how-do-i-access-administration-part-settings--maintenance-in-superoffice-crm/)
2. Select the user you want to remove in the **Associates** list.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6137161-SCG94XdcezBaHmxFXUSFg0AmRriM91STMJInK6dybusKfJTIYGwrcxYcCXr7XDrx-0/image-20250320101120-1.png)
3. Then the user’s details will appear on the right-hand side of the screen. Mark the **Former Employee** checkbox. At the bottom of the screen, the switch that determines if a user can log in or not will automatically be switched off.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6137170-7tL8S24II9x0dddOhaSSadfASIbhqnCWUqYhIQ2pHjMdzAWOOlHm6NU2KU7AAnRz-0/image-20250320101252-2.png)
4. Now the user will not be able to log in. All the information created by this user in SuperOffice CRM is still owned by him/her and has a reference to this user, if you did not update his/her records with a bulk update to another user.

​

**Delete the user**

**Note!** Consider carefully if you want to delete a user. This change cannot be undone. Before you delete a user, we recommend updating all active records (Companies, sales, activities, etc.) to another user. After deleting a user, the records created by this user will not be linked to a user anymore.

1. Login to SuperOffice CRM and access [Settings and Maintenance](https://community.superoffice.com/en/support-faqs/faq/how-do-i-access-administration-part-settings--maintenance-in-superoffice-crm/).
2. Select the user you want to remove in the **Associates** list and click the **Delete** button.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6137171-ykxSZKuIN3z3kC44HSxnFkhO3u3r7gUbwbJyKH1OOQ0wYzX1c5bUJ7PXdbHWgcwH-0/image-20250320101325-3.png)
3. Confirm your action by clicking **OK**.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6137172-fwS4XFYNthq0fbzJfzF32IapT013O4wj30guZK2AWDnHSgFpAcMmLdROyWIj2BF7-0/image-20250320101347-4.png)
4. Now the user will not be able to login, and all the information created by this user in SuperOffice CRM is not owned by anyone and has no reference to this or any other user.
