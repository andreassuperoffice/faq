# How do I enable TO, FROM, CC labels/fields on the requests (tickets) in SuperOffice Service?

Updated on 28 Dec 2025

When I receive messages from the customer, I cannot see their e-mail addresses. Also, whether there was anyone else included in the conversation (CC). Is it possible to get TO, FROM, and CC labels visible?

![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465310-QCdm4OJs9hAuW9ick3Ly5JF7t90iXQkBW3gjH40jriFu0fQdq4AKzrNTazcqLq1p-0/image-20251228084901-1.png)

It is possible to enable these (TO, FROM, CC) labels by configuring the mailbox, which is used to import e-mails into SuperOffice Service. Please follow the steps below:

1. Click on ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465311-SCSclGT7ULkWBekkd2HgPsq5tfAIZ2k8ZXnreNfZQ5kiJ0H25KYAjeIJUz1Lcyje-0/image-20251228084923-2.png), then Settings and maintenance**.**

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465312-UpUYDk6FLn8rR206mOUkmz7WCW4P1FaD7aFGnY898IQclxARxpjCFJSWOGyf7768-0/image-20251228085007-3.png)
2. Navigate to Requests (1). In the **Mailbox** (2) list, double-click on the mailbox (3), which is assigned to the Category where you want to see the e-mail message labels.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465313-C8M3ezoLyTGZyTDRIPUHAkToSCjS0OrGEeRIg477ppbw1QmMIWLd92hKgrkGXcoo-0/image-20251228085028-4.png)
3. In the **E-mail fields** (1) type the label names separated by a comma that you want to see. For example: TO, FROM, CC, and click OK (2) to save it.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465314-rY2N0g5hGOONDte00wLNGYbPlWo6b6qXBT2wXKKb3pH3qaIFqfMeeAJMHtxN8k05-0/image-20251228085403-5.png)
4. Now, when the messages are imported to this category, FROM, TO, and CC labels with the e-mail addresses will be visible in Service.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6465315-xw3OhUst1y39P2Yo0l5OKy8D44SfHBWPicctBSS4sduy8kc1rmwh4ReoPliwXMxm-0/image-20251228091625-6.png)
