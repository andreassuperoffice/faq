# How do I create a quote document and e-mail templates in SuperOffice CRM?

Updated on 16 Jul 2025

How do I create a quote document and e-mail templates in SuperOffice CRM?

To create a quote document template and e-mail templates, please follow the steps below:

1. Decide which particular Quote document template you want to create. Please check [this FAQ](https://community.superoffice.com/en/support-faqs/faq/what-are-the-different-types-of-quote-document-templates-and-when-are-they-used-in-superoffice-crm/) to understand the difference between the quote template types.
2. To create a document template, please check [this FAQ](https://community.superoffice.com/en/support-faqs/faq/how-do-i-upload-and-use-document-templates-in-superoffice-crm/) to learn how to do it.

   **Note!** When creating a document template, please remember to select the **Quote document type**.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6270514-ilB97opRuq7Lfqf0Cx01Hk1CWnJAHGEw4arZeEZH7WaAJf0Aisz5HnJd4pQriLUG-0/image-20250716105032-1.png)
3. To create an e-mail template, please check [this FAQ](https://community.superoffice.com/en/support-faqs/faq/how-do-i-create-and-use-e-mail-templates-in-superoffice-crm/) to learn how to do it.

   **Note!** When creating a quote e-mail template, please remember to choose **Template type:** Quote or Order confirmation.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6270552-0FHB2qTMpbaNmCH4IOmaTYoaYkYyLZ6cMw2qlM65FGZx7ufedTPlg931TUEw66hd-0/image-20250716110110-2.png)
4. In the quote templates, you can use template variables that will fill in the information automatically. [Here](https://docs.superoffice.com/en/document/templates/learn/template-variables.html) you can find a list of all available template variables. You can also use merge field functionality. Please read [this blog](https://community.superoffice.com/en/technical/blogs/archive/quote-template---insert-template-variables/) post on how to add these fields.
