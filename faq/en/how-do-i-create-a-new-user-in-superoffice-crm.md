# How do I create a new user in SuperOffice CRM?

Updated on 28 Apr 2026

I want to create a new SuperOffice user. How do I do it?

To be able to add a new user to your SuperOffice CRM, you need to:

1. Log in as a SuperOffice Administrator and log in to Settings and maintenance. Please check [this FAQ](https://community.superoffice.com/en/support-faqs/faq/how-do-i-access-administration-part-settings--maintenance-in-superoffice-crm/) for more information.
2. Have enough free SuperOffice CRM licenses. A new license can be ordered from your SuperOffice account manager.

To create a new SuperOffice user, please follow the steps below:

1. Click on the **Users** (1) button in the left-side Navigator panel, then select the **Associates**(2) tab and click on **+Add** (3).

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6653306-IQo34YcwKE3XffAUBNPNrIWjUnZp4KyOiYK8pWMltCp5bguHo6loFcU45iF9mbQ8-0/image-20260428150813-1.png)
2. Create a new user by filling in the details in the new empty dialog fields, which appear on the right side of the screen. Start by filling in **Name** (1), **Last name** (2), and **E-mail address** (3). Then make sure the SuperOffice **User name** (4) is equal to the username in your identity provider's system (when you use Office 365 or Gmail for authentication). When you use SuperOffice for authentication, simply fill in your e-mail address.Next, assign the **[Role](https://docs.superoffice.com/en/admin/user-management/role/index.html)** (5) and a **User plan** (6). User Plan is a mandatory field because it determines which set of features the new user will have. Select **Primary** **group** (7), and you can click **Save** (8) to finish.

   **Note!** E-mail addressed filled in in the **User name** (4) field must be valid, because it will be used for account confirmation.

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6653336-2noR6reXbOlZ8jP0kfGfitb7xz6nBsta0REu5gOK2d5ozWY1ZniohaMuiz18wI64-0/image-20260428151617-2.png)
3. The user will receive an invitation email in their inbox. They need to click the activation link to enable their account.

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6648113-ynk46M7RFGHKGKSw8AnXER81oguAUEWmQPeYzCMO6DIIulwrJTf506ByczPCXMAz-0/image-20260424140621-3.png)
4. You might want to complete your user set-up by assigning **Other groups and Service categories,**as shown below. These fields determine which data access rights your new user will have. Please read [this FAQ](https://community.superoffice.com/en/support-faqs/faq/how-do-i-configure-what-information-the-users-of-our-company-can-access-in-superoffice-crm/) for more information about access setup.

   ![](https://app.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6653439-5ihBqCgTSoZtdAl5diS2wgc8rbiM6GjSomssBnDK2369lkeWa0rZXNMeE9l5oOYq-0/image-20260428151906-4.png)
