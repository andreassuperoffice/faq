# How do I use SuperOffice with the new Outlook?

Updated on 25 Apr 2025

I've started using the new Outlook, and I'm finding that SuperOffice MailLink doesn't work the same way. It seems like archiving e-mails and opening archived e-mails from SuperOffice is different. How can I set up SuperOffice to work effectively with the new Outlook?

The new Outlook is a web-based version that doesn't support COM add-ins like SuperOffice MailLink. Because of this, opening the email client from SuperOffice, creating new emails from SuperOffice in Outlook, and opening previously archived emails in Outlook are no longer functions available through this integration.

To integrate with the new Outlook, we recommend using SuperOffice for Outlook, an app that works across all platforms, including web, mobile, and desktop, and configuring the SuperOffice Inbox for sending emails.

**To archive e-mails and access SuperOffice features in the new Outlook, please follow the steps below:**

#### **Step 1. Install and Use SuperOffice for Outlook**

1. Go to the SuperOffice App Store page for [SuperOffice for Outlook](https://appstore.superoffice.com/superoffice-as/superoffice-for-outlook) and follow the instructions on the App Store page to get the app. For detailed installation instructions, refer to the SuperOffice documentation: [Learn about SuperOffice for Outlook](https://docs.superoffice.com/en/email/superoffice-for-outlook/learn/index.html).
2. Open an e-mail in the new Outlook.
3. Click the **SuperOffice icon**.

![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6086991-ddKkSnbsObYfyW7a4Mrr1ttt1Z6Cg86JGADCnPA01izYJosjE7waIUybRXOQxN0w-0/image-20250213214759-19.png)

4. Use the SuperOffice interface to archive the e-mail directly to SuperOffice.

![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6087000-LrLQlu4SAHGM3uq3f1oKEFcjIbAsfnw2Xr0pcjze3gGF0RPuuXeYyH1ss5xhnnL2-0/image-20250213220542-1.png)

5. After archiving, you can easily open the contact card in SuperOffice by clicking a button or link within the SuperOffice interface.

![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6087001-73aiJKxCWHFutOIeoX1yH1cLbXunFqeQg1F44i8iO7H2DTnQPPEmhMFftMynWyYF-0/image-20250213220609-2.png)

#### **Step 2. Adjust Settings for Opening Archived E-mails**

To ensure archived e-mails open correctly in SuperOffice, you need to configure your settings.

1. In SuperOffice CRM, go to your Local settings.

![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6086987-LQIthSrCT652yJz0fhuK0teUj6IwcRYTiR1Rn35zNAsWGm5mymXYHAoZFq5JGna9-0/image-20250213214759-22.png)

2. Find the settings related to E-mail client and make sure you have SuperOffice CRM, and not Microsoft Outlook selected. This will make sure that SuperOffice MailLink is not trying to launch your old Outlook installation.

![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6086986-UB73tHWQEmjnBT34UHjaHNETAMPmAtg5zj6UQgwXMYXxxkFiFZrLNnpO68HdoYHO-0/image-20250213214759-23.png)

With this setup all e-mails will open directly in SuperOffice for easy reading.

![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6087002-kAjwNTBS9wBNnFlEmGryuZilQ8ytdRoCzRmbLKRKHF812ftnki5wBPpGJim2UKs5-0/image-20250213220641-3.png)

#### **Step 3. Set Up the SuperOffice Inbox**

We recommend to set up and use the SuperOffice Inbox if you are using new Outlook.

Here you will find detailed instructions on how to set up SuperOffice Inbox: [How do I start using SuperOffice Inbox?](https://community.superoffice.com/en/support-faqs/faq/how-do-i-start-using-the-superoffice-inbox/)

**Note!** If you don't configure the SuperOffice Inbox, you will no longer be able to send email invitations from SuperOffice.
