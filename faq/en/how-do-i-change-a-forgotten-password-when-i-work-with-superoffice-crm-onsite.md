# How do I change a forgotten password when I work with SuperOffice CRM Onsite?

Updated on 26 Mar 2026

How do I change a forgotten password when I work with SuperOffice CRM Onsite?

There are three ways you can change the password when your SuperOffice CRM is hosted on the company's server:

- [Change your password yourself](https://community.superoffice.com/en/support-faqs/faq/how-do-i-change-a-forgotten-password-when-i-work-with-superoffice-crm-onsite/#1)
- [SuperOffice CRM administrator can change it for you](https://community.superoffice.com/en/support-faqs/faq/how-do-i-change-a-forgotten-password-when-i-work-with-superoffice-crm-onsite/#2)
- [A SuperOffice system user can change it for you](https://community.superoffice.com/en/support-faqs/faq/how-do-i-change-a-forgotten-password-when-i-work-with-superoffice-crm-onsite/#3)

**Change your password yourself**

If you use the same password (and username) to log in to your other business applications and devices (Active Directory authentication), you can change the password in the system where the authentication is managed.

Customers often decide to use the Microsoft service for managing the username and password for SuperOffice CRM. If you need help to understand where your password is stored, please contact your SuperOffice CRM administrator.

**SuperOffice administrator can change it for you**

If you use the SuperOffice CRM password that is stored in the SuperOffice database, please ask your SuperOffice administrator to reset the password for you. The administrator should follow the steps below:

1. Log in to [Settings and maintenance](https://community.superoffice.com/en/support-faqs/faq/how-do-i-access-administration-part-settings--maintenance-in-superoffice-crm/).
2. Go to the **[Users](https://docs.superoffice.com/en/admin/user-management/update-user.html)** section and then, in the **Associates**tab, find the user and select it from the list. In the **Password** (1) field, type a temporary password for one-time login, and **Save** (2)the user.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6607215-mZ5ltNeAg1W89yCbKyp8nOMebhwJqhpYZP1zT6kxc2TSmzofrxf5w5O0KRQfAJtw-0/image-20260326174029-2.png)
3. Once you get informed that the password has been changed, log in to SuperOffice CRM with the temporary password, click on your user icon, and select **Change password.**

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6607208-MP32BqmMZ9eLTgnCD1g9eroNjFbwCltI8hiXhDAiCWF6howx0GgjnWSgNhfg1Qa0-0/image-20260326173820-1.png)
4. Type in the temporary password and your new, [secure](https://www.lastpass.com/features/password-generator) password.

**A SuperOffice system user can change it for you**

If you are the only user of SuperOffice CRM with the administrator's role and you forgot your password, you can log in to [Settings and maintenance](https://community.superoffice.com/en/support-faqs/faq/how-do-i-access-administration-part-settings--maintenance-in-superoffice-crm/) with a System user's credentials and reset your password.

System user credentials can be found in the Technical Installation Documentation. SuperOffice does not store this information and, as a result, cannot provide it at your request.
