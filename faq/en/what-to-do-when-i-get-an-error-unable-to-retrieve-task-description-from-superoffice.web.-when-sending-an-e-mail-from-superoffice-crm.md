# What to do when I get an error "Unable to retrieve task description from SuperOffice.Web." when sending an e-mail from SuperOffice CRM?

Updated on 9 May 2025

I'm sending an e-mail from SuperOffice CRM and the error comes up:

*Unable to retrieve task description from SuperOffice.Web.
ID: mailtask(13)
URL: https://online.superoffice.com/custXXXX/services/maillinkservice.svc*

Why does it happen and how do I fix it?

![](https://online2.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/4414051-GsrIUdon7btBmjdW5EG9rpZZKo8o53kjYjCQoyfOCyI0LOr94d9zGLi6bCX6bSkL-0/image.png)

There are few known situations when this error can occur:

1. When SuperOffice MailLink has incorrect configuration. Try to reconfigure SuperOffice MailLink, please follow [this FAQ](https://community.superoffice.com/en/support-faqs/faq/how-do-i-configure-superoffice-maillink-for-outlook-manually/) to do it.
2. When *SuperOffice.Mail.ProtocolHandler.exe*component has wrong values in Windows Registry. Please try to follow [this FAQ](https://community.superoffice.com/en/support-faqs/faq/what-to-do-when-i-get-an-error-no-application-is-associated-with-the-specified-file-for-this-operationwhen-connecting-superoffice-web-tools/) to solve it.
