# What to do when newly created "Project Status" is not visible in SuperOffice CRM?

Updated on 27 Nov 2025

I have created a new list item for **Project - Status,**but it is not visible in SuperOffice CRM when I create a new project. Why does it happen, and how can I make it visible?

To make a new project status visible, you need to create a new item in **Project - Status**in Settings and Maintenance, and also link it to **Project Type**. Please follow the steps below to do it:

1. Log in to [Settings and Maintenance](https://community.superoffice.com/en/support-faqs/faq/how-do-i-access-administration-part-settings--maintenance-in-superoffice-crm/).
2. Click on **Lists (1)**, select **Project - Status (2)**from the selection list, and click on **+Add (3).**

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6420569-2c46hOjBqD17Jc1cth24IAS6k61oH7jMtYACcKuwKmgRtfIwIRWkWKPmQG1ZLD9K-0/image-20251127150706-1.png)
3. Enter **Project status (1)** name and **Description (2)**if needed, and click **Save (3).**

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6420590-qkKKysmud4KPNP11Qlh5X43nxQFlZLujBSN6YqWaSCuwKBK3XrcntJblSiLnIIpw-0/image-20251127151055-2.png)
4. Then select**Project - Type, Status (1)** from the drop-down list, and double click on the **Project type (2)**to which you want to assign the project status.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6420617-ZDcH6e1Ul8xaHj2BMe5keYTLLJFME59mnRZm3WkZkfXyMm33rhjxTp0slKHyWLh7-0/image-20251127151257-3.png)
5. Select the new project status (1)you created and click **Save** (2). This will make a new status visible under this project type in SuperOffice CRM.

   ![](https://online3.superoffice.com/Cust1990/CS/scripts/customer.fcgi/getAttachment/6420634-8ZUX3nqo5xGilspWxen0QIWDQlnIsU3T738I9ljpqoCXHHj7i3NnIaE4xUcjCx0J-0/image-20251127151755-4.png)
